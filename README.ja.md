## アプリについて

ヤハギは、ゲーム画面とよく使う支援情報をまとめて表示します。プレイ中は艦隊の状態、任務の進捗、戦闘予測、航海日誌を確認できます。出撃の準備や日々の計画には、改修計画、開発計算、遠征条件の確認、海域情報、経験値計算などのツールを利用できます。

スマートフォン、タブレット、折りたたみ端末に対応し、調整可能な情報レイアウトと、大画面向けの HD レイアウトを用意しています。UI は簡体字中国語、繁体字中国語、日本語、英語、韓国語に対応しています。

ゲーム内の操作は、すべてプレイヤー本人が行います。ヤハギはゲームページがすでに受信したデータを支援情報として整理し、編成、補給、出撃、開発、改修、任務受領を代行することはありません。

## ダウンロードとインストール

[GitHub Releases](https://github.com/yamatosaki/yahagi-kancolle-browser/releases/latest) から、公開済みのバージョン、インストールパッケージ、各バージョンの説明を入手できます。

| プラットフォーム | 入手方法と注意点 |
| --- | --- |
| Android | 本プロジェクトが主に保守しているバージョンです。リリースページから APK をダウンロードしてインストールしてください。 |
| iOS | [Kutinana](https://github.com/Kutinana) 氏によるサードパーティー移植版の IPA をリリースページで提供しています。インストール方法、対応機能、保守状況は、各バージョンのリリース説明をご確認ください。 |

Android 版を更新する際は、リリース説明に従って上書きインストールしてください。アプリのアンインストール、アプリデータの消去、端末の変更を行う前に、残しておきたい航海日誌と編成記録をエクスポートしてください。

## 機能一覧

| 機能 | できること |
| --- | --- |
| 艦隊・戦闘支援 | 艦隊の状態、制空・索敵情報を確認し、戦闘予測で戦闘経過や結果の予測を表示できます。出撃前の状態確認も行えます。 |
| 任務情報 | 任務の説明、報酬、前提・後続任務を確認し、任務の絞り込みや一部任務の項目別進捗の追跡ができます。 |
| 艦娘・装備 | 保有・未保有の図鑑を閲覧し、絞り込みや並べ替え、装備状況の確認、艦娘ごとの装備可否の検索ができます。 |
| 日々の計画 | 改修の実施日や消費資材を調べ、開発レシピと確率を計算し、遠征条件や見込める収益を確認できます。 |
| 戦果・育成 | 戦果記録やカレンダーを確認し、目標戦果、レベルアップに必要な経験値・出撃回数を計算して、育成目標を保存できます。 |
| 編成・海域 | 艦隊・基地航空隊の編成を保存し、編成画像や外部ツール向けデータを出力できます。海域のルート、マス、敵艦情報も確認できます。 |
| 日誌・バックアップ | 6 種類の航海記録と資源推移を確認し、出撃記録を絞り込んで戦闘詳細を表示できます。日誌・編成記録のエクスポート、同期、復元にも対応しています。 |
| モバイルでの使いやすさ | 画面や資源バーをカスタマイズでき、完了通知、バックグラウンドのカウントダウン、ゲームリソースのキャッシュ、マウス互換設定を利用できます。 |

### 艦隊情報と戦闘予測

- 艦娘のレベル、耐久、疲労度、燃料、弾薬、装備と、艦隊全体の集計情報を確認できます。
- 制空・索敵などの参考情報や、遠征、入渠、建造、泊地修理の状態を確認できます。
- 通常艦隊・連合艦隊の戦闘情報に対応し、敵味方の耐久変化、勝利ランク、MVP の予測を表示します。
- 出撃前の状態確認、大破時の警告、戦闘前の敵艦情報表示を利用できます。

戦闘予測は、ゲームページがすでに受信した戦闘データをもとに情報を整理します。公式の戦闘結果を受信した後は、確定結果に更新します。予測や状態表示は参考情報として、ゲーム画面と併せてご判断ください。

### 任務情報

- 受領中の任務や任務データを閲覧し、種類・周期などの条件で絞り込みや検索ができます。
- 任務の説明、基本報酬、前提・後続任務を確認し、任務を進める順序の計画に役立てられます。
- 一部の任務では項目別の進捗を追跡し、達成をお知らせします。
- 任務データの更新に対応しています。

一部の任務の進捗は、端末内で観測・記録した情報から推定します。アプリがまだ観測していない進捗は、反映されていない場合があります。

### 艦娘・装備

- 保有・未保有の艦娘や装備を分類して表示し、条件に応じた絞り込みや並べ替えができます。
- 装備の改修値、熟練度、装備状況を確認できます。
- 装備から搭載可能な艦娘を、艦娘から使用可能な装備を検索できます。通常スロットと補強増設スロットを区別して確認できます。

### 改修・開発・遠征の計画

- **改修計画：** 曜日、装備分類、キーワード、お気に入りから検索し、二番艦の条件、消費資材、更新ルートを確認できます。
- **開発計算：** 秘書艦と投入資源から目標装備の開発確率を調べたり、目標装備からレシピを検索したりできます。
- **遠征条件の確認：** 艦種、レベル、装備、補給、士気などの条件を確認し、大成功率、収益、完了時刻を推定できます。

### 戦果・経験値の計画

- 端末内の戦果情報、出撃記録、戦果カレンダーを確認できます。
- EO や任務の戦果報酬を含めて目標を立て、残りの必要戦果や 1 日あたりの必要量を推定できます。
- 海域、ルート、勝利ランク、旗艦、MVP などの条件から経験値を計算し、レベルアップに必要な出撃回数を推定できます。
- 艦娘の育成目標を保存し、経験値やレベルの進捗を継続して確認できます。

戦果・経験値の計算は、記録済みのデータと設定した条件に基づく推定です。

### 編成記録・海域情報

- 現在の艦隊・基地航空隊の編成を保存し、名前や海域などの条件で記録を検索できます。
- 高解像度の編成画像を出力し、共有や攻略情報の整理に利用できます。
- DeckBuilder データをエクスポートしたり、制空権シミュレータや Jervis などの外部ツールを開いて計算を続けたりできます。
- 海域のルート図、マスの種類、敵編成、陣形、経験値、制空の参考情報を確認できます。敵艦をタップすると詳細情報を表示します。
- 海域・敵艦などのデータは、アプリ内で個別に更新を確認できます。

保存した編成は閲覧・共有用です。ゲーム内の編成操作はプレイヤー本人が行います。海域や敵艦のデータはゲームの更新に伴って変わる場合があるため、実際のゲーム内容をご確認ください。

### 航海日誌・資源推移・バックアップ

- 出撃、遠征、建造、開発、除籍、資源の 6 種類の記録を保存します。
- 日付、海域、状態などの条件で出撃記録を絞り込み、マスや戦闘の詳細を確認できます。
- 各資源の保有量の推移、期間内の増減、過去の記録を確認できます。
- 現在のアカウントの航海日誌・編成記録をエクスポート、共有、復元できます。ドキュメントフォルダーを選択し、バックグラウンド同期や手動同期を行うこともできます。

記録は、アプリが実際に観測したデータから蓄積されます。バックアップの対象は航海日誌と編成記録です。ログイン用のアカウント・パスワード、ログイン Cookie、アプリ設定全体は含みません。

### 画面・通知・ゲームキャッシュ

- 全画面表示、ゲーム画面のサイズ調整、情報パネルの調整、ホーム画面のモジュール編集に対応しています。モジュールの並べ替え、非表示、初期レイアウトへのリセットができます。
- 編成情報と上部の資源バーは、一部の表示項目をカスタマイズできます。
- 遠征、入渠、建造、泊地修理、疲労に関する通知とカウントダウンを表示します。
- ゲームリソースのキャッシュと端末への一括ダウンロードに対応し、一時停止、再開、整合性の確認、削除ができます。
- 画面・フレームレートの設定、外付けマウスでの操作、マウスホイールの互換設定に対応しています。

通知とバックグラウンド動作は、システムの権限や省電力設定の影響を受けます。リソースキャッシュは繰り返しの読み込みを減らすための機能です。プレイ中はゲームサーバーへの接続が必要です。

## 使い始めるには

1. リリースページからインストールパッケージをダウンロードし、各バージョンの説明に従ってインストールして、アプリを開きます。
2. 接続方法を選び、ゲームページでログインします。必要に応じて、システムネットワーク、HTTP プロキシ、SOCKS5 プロキシを設定できます。
3. 母港に入り、アプリが艦隊・アカウントのデータを受信してから、艦隊、任務、所持艦娘・装備などの支援画面を開きます。
4. 端末のサイズに合わせてレイアウトを調整し、必要に応じて通知、キャッシュ、記録のバックアップを設定します。

アプリには 2 つの動作モードがあります。

- **ゲーム情報モード：** ゲームページがすでに受信した API レスポンスを読み取り、艦隊、任務、戦闘、日誌などの支援機能を有効にします。
- **ブラウザ専用モード：** API 情報の読み取りを停止し、アプリ内でゲームページを閲覧・操作します。

DMM の入口に加え、実験的な OOI のサードパーティー接続も用意しています。OOI を利用する場合、ログイン情報は当該サードパーティーサービスに送信されます。アプリ内の説明を確認したうえでご利用ください。

## データとプライバシー

支援用の記録は主に端末内に保存され、アプリ独自のクラウドアカウント登録は不要です。各機能のデータの取り扱いは次のとおりです。

| 項目 | データの取り扱い |
| --- | --- |
| 航海日誌・編成記録 | 端末内に保存します。ユーザーの操作でエクスポート、復元、指定したドキュメントフォルダーへの同期を行います。 |
| 匿名の端末・利用統計 | TelemetryDeck で端末情報や現在の描画モードなどの匿名の利用統計を収集します。初期設定では有効で、設定から無効にできます。 |
| KCWiki へのデータ提供 | 初期設定では無効です。バージョンと構成が対応している場合、ユーザーが有効にするかどうかを選択できます。 |
| 診断ファイル | ユーザーが手動で保存するか、システムの共有メニューから送信します。アプリが診断ファイルを自動アップロードすることはありません。 |

支援情報の解析に使用するゲーム API 情報からは、api_token、api_starttime などの機密パラメーターを除去します。記録のバックアップにログイン Cookie は含まれません。ただし、システム WebView が標準の仕組みに従って、ログイン状態を端末内に保存する場合があります。
