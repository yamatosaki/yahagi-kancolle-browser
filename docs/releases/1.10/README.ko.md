이번 버전에서는 **Kanxy 모드**를 지원하고 「출격 경험치」와 함대 수송량(TP)을 추가했습니다. **게임 내 중국어 번역 팩의 호환성 문제**도 수정했습니다. 휴대폰, 태블릿, 폴더블 기기에서의 화면 표시와 조작도 개선했습니다.

Android에서는 **v1.0.9와 이전에 배포한 v1.10 베타 버전 위에 바로 설치**할 수 있습니다. 기존 앱을 삭제하면 앱에 저장된 데이터를 잃을 수 있으므로 그대로 둔 상태에서 업데이트해 주세요.

**iOS 1.10 버전을 독자적으로 이식하고 제작해 주신 GitHub 사용자 [@Kutinana](https://github.com/Kutinana) 님께 감사드립니다.**

**iOS 설치 방법**

기존의 **IPA 사이드로딩** 외에 이식판 제작자가 제공하는 **TestFlight 공개 테스트**로도 설치할 수 있습니다. 무료 Apple 개인 개발자 계정으로 사이드로딩하던 분은 TestFlight를 이용하면 7일마다 앱에 다시 서명할 필요가 없으며, 새 테스트 버전도 쉽게 받을 수 있습니다.

- **사용 기간**　각 TestFlight 빌드는 개발자가 업로드한 날부터 최대 **90일** 동안 사용할 수 있습니다. 남은 기간은 TestFlight에서 확인하고, 만료 전에 이식판 제작자가 제공하는 업데이트를 확인해 주세요.
- **참가 인원**　TestFlight 외부 테스트는 최대 **10,000명**까지 지원합니다. 현재 모집 인원과 참가 가능 여부는 초대 페이지에서 확인해 주세요.
- **설치 순서**　App Store에서 Apple의 **TestFlight**를 먼저 설치한 뒤, 아래 링크를 열어 테스트에 참가하고 앱을 설치해 주세요.

**[iOS 버전 TestFlight 공개 테스트 참가하기](https://testflight.apple.com/join/WWU4StEm)**

iOS 이식판의 기능, 호환성, 후속 업데이트는 이식판 제작자의 안내와 실제 배포 버전을 기준으로 확인해 주세요.

## 1. 새 기능 및 주요 개선

### 1. Android에서 Kanxy 모드 지원

야하기에서 Kanxy의 VPN 또는 로컬 HTTP 프록시를 통해 게임 리소스를 불러올 수 있습니다. 게임 도중 연결 방식을 바꿔 새로고침이 필요한 경우, 게임이 다시 포그라운드에 있고 모항에 있는 것이 확인되면 새로고침합니다.

**처음 사용할 때는 Kanxy를 먼저 설정한 다음 야하기를 설정해 주세요.**

1. **모드 팩 선택.** Kanxy의 모드 설정(魔改设置)에서 모드를 켜고 사용할 팩을 내려받거나 선택합니다. Kanxy 자체 리소스 캐시도 함께 켜는 것을 권장합니다. 인증서 설치 안내가 나오면 Kanxy의 안내를 따릅니다.
2. **HTTP 프록시 켜기.** Kanxy에서 HTTP 프록시를 켠 뒤 표시되는 수신 주소와 포트를 확인합니다. 두 앱을 같은 휴대폰에 설치한 경우 야하기에 입력할 주소는 `127.0.0.1`이며, 포트는 Kanxy에 표시된 값을 입력합니다.
3. **야하기 연결.** 「설정 → 네트워크 및 연결」에서 「HTTP 프록시」를 선택하고 주소와 포트를 입력한 뒤 「설정 적용 후 게임 새로고침」을 누릅니다. 야하기의 원본 리소스에는 보통 「임시 캐시」를 사용하면 됩니다. Kanxy 이미지는 별도로 캐시되며, Kanxy를 경유하는 동안에는 원본 리소스 사전 다운로드가 일시 중지됩니다.

**Kanxy 모드 팩을 바꿀 때**

Kanxy에서 새 팩을 선택하고 교체할 기존 팩을 끕니다. 야하기의 「설정 → 데이터 관리」를 열고 「게임 리소스 로컬 캐시」에서 「Kanxy 캐시 삭제 및 게임 새로고침」을 누릅니다. 타이틀 화면으로 돌아가면 **GAME START**를 누릅니다. 같은 모드 팩을 계속 쓸 때는 바로 게임에 접속하면 됩니다.

**Kanxy 모드와 야하기 로컬 모드를 함께 쓸 때**

두 모드가 같은 이미지를 교체하면 야하기 로컬 팩의 이미지가 우선 표시됩니다. 해당 이미지에 Kanxy 모드를 적용하려면 「야하기 → 도구 상자 → 모드」에서 해당 리소스를 끄고 「적용 후 게임 새로고침」을 누른 다음, 위의 팩 교체 순서를 따릅니다.

### 2. 「출격 경험치」에서 함선별 경험치와 MVP 횟수 확인

- 일반 레이아웃과 HD 레이아웃 모두에서 「출격 경험치」 요약을 표시할 수 있습니다. 출격이나 연습이 끝나면 각 함선이 획득한 경험치, 다음 레벨까지의 진행도, MVP 횟수를 확인할 수 있습니다. 연합함대는 주력함대와 호위함대로 나누어 표시합니다.
- 항해 일지에 **「경험치」** 탭을 추가했습니다. 출격과 연습마다 참가 함대와 함선별 기록을 다시 볼 수 있습니다. 장기간의 육성 성과를 집계하려면 요약에서 현재 계정의 「총 누적」을 켜세요. 획득 경험치와 MVP 횟수를 누적합니다. 기본값은 꺼짐이며, 항해 일지의 경험치 기록은 이 설정과 관계없이 저장됩니다.
- 기록 백업에 항해 일지의 경험치 기록을 포함하며, 이전 버전의 백업도 지원합니다. 데이터가 누락된 기록에는 「일부 기록」이라고 표시합니다.

### 3. 함대 요약에 수송량 추가 및 함대 상태 표시 개선

- 함대 편성에서 일반 수송량과 전차 수송량(TP)을 함께 볼 수 있습니다. 상세 화면에서는 S승과 A승의 예상 수송량을 비교할 수 있습니다. 연합함대는 제1·제2함대가 각각 기여하는 수송량과 해당하는 경우 키누 개2의 기본 수송 보너스도 표시합니다. 편성 이미지와 편성 기록에서도 수송량을 확인할 수 있습니다.
- 함대 탭의 색으로 출격 중, 연습 중, 원정 중, 보급 필요 등의 상태를 구분합니다. 원정 함대가 귀환하면 칸무스의 최신 연료·탄약 정보를 받은 뒤 보급 필요 여부를 판단합니다. 함대 요약과 칸무스 상세 화면은 중파·대파 상태에 맞춰 손상 일러스트를 표시합니다.

### 4. 게임 내 중국어 번역 팩 호환성 수정 및 ZIP 업데이트 지원

중국어 번역 팩을 교체한 뒤에도 이전 글꼴이 표시되던 문제를 수정했습니다. 「도구 상자 → 모드」에서 지원되는 번역 팩 ZIP을 가져오면 팩 구성에 따라 게임 화면의 이미지와 글꼴을 교체하고, 게임 내 임무 제목과 설명, 게임 문구, BGM 곡명을 중국어로 표시할 수 있습니다. **`Kancolle_to_CHS` v1.4.0의 배포 ZIP을 그대로 가져올 수 있습니다.** 인식된 리소스는 사전 검사에서 확인할 수 있습니다.

**[Kancolle_to_CHS 배포 안내](https://bbs.nga.cn/read.php?tid=44139718)**

번역 팩이나 일러스트 팩의 새 버전이 나오면 설치한 팩의 상세 화면에서 「ZIP에서 업데이트」를 선택합니다. 추가되거나 제거될 리소스를 미리 볼 수 있습니다. 기존 리소스의 선택 상태, 팩의 사용 여부와 우선순위는 유지됩니다. 새로 추가된 지원 리소스는 기본으로 선택됩니다. 내용을 확인한 뒤 「적용 후 게임 새로고침」을 누르면 새 버전이 적용됩니다.

Android 갤러리에서 공유 모드 폴더의 리소스를 건너뛰도록 해, 시스템 갤러리에 칸무스 일러스트가 나타나는 경우를 줄였습니다.

### 5. 「함대 정보 동기화」 추가

「설정 → 출격 및 전투 → 전투 예측 → 함대 정보 동기화」에서 함대 요약에 내구와 응급수리 장비 소모를 반영할 시점을 선택할 수 있습니다.

- **즉시 동기화(기본값)**　전투 데이터를 받으면 바로 반영하므로 전투 도중에도 최신 상태를 확인할 수 있습니다.
- **전투 결과 수신 시**　해당 전투의 결과가 나온 뒤 반영합니다. 게임에서 결과를 확인하는 시점에 맞춰 함대 상태를 보고 싶은 경우에 적합합니다.

### 6. 「시작 상태 확인」 추가 및 기본 활성화

게임에 접속하면 「연결 준비」, 「접속 페이지」, 「게임 시작」 세 단계가 차례로 표시됩니다. 로딩이 멈추면 계속 기다리거나 다시 불러올 수 있습니다. 연결에 실패한 경우에는 실패한 단계와 호스트, 오류 코드를 확인하고 복사할 수 있으며, 안내창을 바로 닫을 수도 있습니다.

「시작 상태 확인」은 기본으로 켜져 있으며 「설정 → 게임 실행」에서 끄거나 다시 켤 수 있습니다.

### 7. 임무 센터에 편성 조건을 충족하는 함대 표시

임무 목록에서 게임 서버가 알려 준 **50% 또는 80%** 등의 진행 단계를 강조해 표시합니다. 상세 화면에서는 서버 진행도를 로컬 집계 위에 표시하므로, 게임이 확인한 진행도와 야하기가 기록한 실제 횟수를 비교할 수 있습니다.

편성 조건 판정을 지원하는 임무의 상세 화면에는 현재 제1~제4함대 중 조건을 충족하는 함대가 표시되어 출격할 함대를 고르기 쉽습니다. 일부 임무에서 출격과 연습 횟수를 혼동하던 문제, 연합함대 호위함 판정 및 보스 지점 인식 문제도 수정했습니다.

### 8. 출격·원정·조작 결과 알림을 항목별로 설정

상단 알림을 **12개 항목별로** 켜고 끌 수 있습니다. 대파, 보급, 보유 한도 등 원하는 알림은 유지하면서 개발, 개수, 연습 경험치, 임무 달성 등의 알림만 따로 끌 수 있습니다.

출격 또는 원정 화면을 열면 설정에 따라 해당 함대의 대파 및 연료·탄약 미보급 상태를 알려 줍니다. 원정을 보낸 뒤 현재 편성이 알려진 성공 조건을 충족하지 않으면 해당 함대의 원정이 실패할 수 있다고 알려 줍니다.

## 2. 수정 및 사용성 개선

- **전투 예측 및 전투 기록**　「전투 예측」에서 해역 미니맵, 적함 미리보기, 예측 결과를 각각 표시할 수 있습니다. 전투 기록에 항모 야습 CI, 여러 종류의 구축함 야간전 CI, 즈이운 입체 공격과 해공 입체 공격의 판별을 추가했습니다. 일부 연합함대 야간전에서 특수공격이 다른 칸무스의 이름 아래 표시되던 문제를 수정했습니다.
- **게임 화면 및 조작**　게임 화면은 원래의 가로세로 비율을 유지한 채 상단 바 아래 중앙에 표시됩니다. 분할 화면의 경계를 드래그하거나 기기를 회전하거나 전체 화면을 전환한 뒤 화면 배율과 터치 위치가 더 잘 맞도록 개선했습니다. 시스템 바를 잠시 표시할 때의 화면 흔들림을 줄이고, 마우스 휠 반응과 앱 복귀 또는 게임 화면 재생성 후 음소거 상태 복원을 개선했습니다.
- **요약 및 도구 상자**　입거 요약에서 연료·강재 소모량과 예상 완료 시각을 함께 표시합니다. 해역 조회에서 페이지를 전환하거나 화면을 회전해도 지도 확대율과 적함 상세 정보가 유지됩니다. 게임 내 기능 영역의 표시 옵션을 그룹별로 배치했습니다. 자료 관리 화면에서 해역, 적함, 임무, 개수, 자막 자료의 업데이트를 바로 확인할 수 있습니다.
- **언어 및 안내**　중국어 간체를 기준으로 중국어 번체, 일본어, 영어, 한국어 문구를 교정했습니다. 응급수리 장비를 장착한 상태와 이미 발동한 상태를 명확히 구분하고, 함대 최저 사기 등 관련 용어를 통일했습니다. 전투 전 적함 미리보기, 모드 라이브러리 검색, 백업 복원에서도 선택한 언어로 앱 안내를 표시합니다.

## 3. 사용 시 참고 사항

- 게임 내 중국어 번역을 사용하려면 리소스 팩을 직접 가져와야 합니다.
- 수송량은 현재 함대 편성과 장비를 바탕으로 추산합니다. 전차 수송량에는 2026년 여름 이벤트의 규칙을 적용합니다. 실제 차감된 TP, 임무 달성 여부, 원정 결과는 게임에서 확인해 주세요.

꾸준히 의견을 보내 주시고 응원해 주시는 제독 여러분께 감사드립니다!
