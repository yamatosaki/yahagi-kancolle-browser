## 一、新增功能与主要改进

### 1. Android 新增 Kanxy 魔改支持

Yahagi 可通过 Kanxy 的 VPN 或本地 HTTP 代理加载游戏资源。游戏中途切换连接时，需要刷新的操作会等到游戏回到前台并确认处于母港后再执行。

**请注意，第一次使用 Kanxy 魔改时，先设置 Kanxy，再设置 Yahagi。**

1. **选择魔改包。** 在 Kanxy 打开「魔改设置」，开启魔改，下载或勾选要用的包。建议同时开启 Kanxy 自带的资源缓存。如果 Kanxy 提示安装证书，按其引导操作。
2. **开启 HTTP 代理。** 在 Kanxy 开启 HTTP 代理，记下它显示的监听地址和端口。两个应用装在同一台手机上时，Yahagi 里的地址填 `127.0.0.1`，端口以 Kanxy 显示的为准。
3. **连接 Yahagi。** 打开「设置 → 网络与连接」，选择「HTTP 代理」，填好地址和端口，点击「应用设置并重新加载游戏」。Yahagi 的原版资源缓存平时选「临时缓存」即可，Kanxy 图片有独立缓存。串联 Kanxy 时，原版资源预下载会暂停。

**以后更换 Kanxy 魔改包**

先在 Kanxy 勾选新包、关闭被替换的旧包，再打开 Yahagi 的「设置 → 数据管理」，在「游戏资源本地缓存」一栏点击「清除 Kanxy 缓存并刷新游戏」。如果回到标题画面，再点 **GAME START**。平时继续使用同一套魔改，直接进入游戏即可。

**Kanxy 和 Yahagi 本地魔改可以一起用**

同一张图在两边都被替换时，优先显示 Yahagi 本地包的图片。想让 Kanxy 接管这张图，先在「Yahagi → 工具箱 → 魔改」里关闭对应资源，点击「应用并刷新游戏」，然后按上面的换包顺序操作。

### 2. 新增「出击经验」，可逐舰查看经验与 MVP 次数

- 普通布局和高清布局都可以显示「出击经验」简报。出击和演习结算后，可逐舰查看获得的经验、等级进度与 MVP 次数。联合舰队分主力和护卫舰队显示。
- 航海日志新增 **「经验」** 页，可回看每次出击和演习的舰队及逐舰明细。要长期统计练级成果，可在简报里开启当前账号的「总累计」，累计经验和 MVP 次数。该开关默认关闭，航海日志的经验记录会独立保存。
- 记录备份已纳入航海日志中的经验记录，并兼容旧版备份。遇到数据缺失时，记录会标明「部分记录」。

### 3. 编队简报新增运输量，舰队状态更直观

- 编队可同时查看 **普通运输量和战车运输量（TP）**。点开详情可对照 S 胜与 A 胜的预计值。联合舰队还会列出第一、第二舰队各自的贡献，以及适用的鬼怒改二加成。编成图和编成记录也可查看运输量。
- 舰队标签用颜色区分出击、演习、远征和待补给等状态。远征舰队归还后，会等到舰娘最新油弹数据再判断是否需要补给。编队简报和舰娘详情也会随中破、大破状态切换受损立绘。

### 4. 修复游戏内汉化包兼容问题，支持从 ZIP 更新

修复了切换汉化包后仍显示旧字体的问题。在「工具箱 → 魔改」中导入受支持的汉化 ZIP，即可按包内内容替换游戏界面图片和字体，并翻译游戏内的任务标题、任务说明、游戏文字及 BGM 曲名。**支持直接导入 `Kancolle_to_CHS` v1.4.0 的发布 ZIP**，在预检中可查看本次识别到的资源。
**Kancolle_to_CHS：https://bbs.nga.cn/read.php?tid=44139718**
汉化包或立绘包有新版时，打开已安装包的详情，选择 **「从 ZIP 更新」**，即可预览新增和移除的资源。已有资源保留原来的勾选状态，包的开关和优先级也会保留。新增且受支持的资源默认勾选，核对后点击「应用并刷新游戏」即可切换。

Android 相册也会跳过共享魔改目录中的素材，减少舰娘立绘出现在系统相册的情况。

### 5. 新增「编队信息同步」

在「设置 → 出击与战斗 → 未卜先知 → 编队信息同步」中，可以选择编队简报更新血量和损管消耗的时机。

- **即时同步（默认）**　收到战斗数据后就更新，战斗进行中也能查看最新情况。
- **结算同步**　等本场战斗结算后再更新，适合希望跟随游戏结算节奏查看编队状态的提督。

### 6. 新增「启动检查」，默认开启

进入游戏时，可以依次看到「准备连接」「入口网页」「启动游戏」三个阶段。加载停滞时可以继续等待或重新加载。连接失败时，可以查看并复制失败阶段、主机和错误码，也可以直接关闭提示。

启动检查默认开启，可在「设置 → 游戏运行」中关闭或重新开启。

### 7. 任务中心显示符合编成条件的舰队

任务列表会高亮游戏服务器返回的进度档位，例如 **50% 或 80%**。点开详情，服务器进度显示在本地计数上方，方便对照游戏已经确认的进度和 Yahagi 记录的具体次数。

对于支持判断编成条件的任务，详情会列出当前第一至第四舰队中符合要求的舰队，方便选队出击。同时修正了部分出击与演习计数混淆、联合舰队护卫舰判定及 Boss 节点识别问题。

### 8. 出击、远征和操作结果提醒可分项设置

顶部通知现在有 **12 项独立开关**。可以保留关心的大破、补给和容量提示，也可以单独关闭开发、改修、演习经验或任务达成等通知。

进入出击或远征页面时，Yahagi 会按设置提示相关舰队的大破和油弹未补给情况。远征派出后，如果当前编成不满足已知的成功条件，会提示该舰队的这次远征「可能失败」。

## 二、修复与体验优化

- **战斗预报与战斗记录**　「未卜先知」可分别选择显示海域小地图、敌舰预览和预测结果。战斗记录补充了空母夜袭 CI、多种驱逐舰夜战 CI、瑞云立体攻击和海空立体攻击的识别，并修正了部分联合舰队夜战特攻显示在错误舰娘名下的问题。
- **游戏画面与操作**　游戏画面在顶栏下方按原比例居中。改善分屏拖动、旋转和全屏切换后的缩放与触摸对齐，减少临时呼出系统栏时的画面抖动。同时改善鼠标滚轮响应，以及返回前台或重建游戏画面后的静音状态恢复。
- **简报与工具箱**　入渠简报将油钢消耗和预计完成时间放在一起。海域查询在切换页面或旋转屏幕后保留地图缩放及敌舰详情。游戏内功能区的显示选项按组排列，资料管理页可直接检查海域、敌舰、任务、改修和字幕资料更新。
- **语言与提示**　以简体中文为基准校订繁中、日文、英文和韩文，明确区分「已装备损管」与「损管已发动」，统一舰队最低士气等术语。战前敌舰预览、魔改库扫描和备份恢复中的应用提示也会跟随所选语言。

## 三、使用提示

- 游戏内汉化需要自行导入资源包。
- 运输量根据当前编成和装备估算，战车运输采用 2026 年夏季活动对应的规则。实际扣除的 TP、任务达成和远征结果，请以游戏内结算为准。
