這次更新加入了 **Kanxy 魔改支援**、**「出擊經驗」與編隊運輸量（TP）**，也修正了**遊戲內漢化包的相容性問題**，並持續改善手機、平板與摺疊螢幕裝置上的操作體驗。

Android 版可從 **v1.0.9 或先前發布的任一 v1.10 Beta 版本直接覆蓋升級**。請保留舊版並直接安裝，以免解除安裝時一併刪除應用程式內的資料。

**感謝 [@Kutinana](https://github.com/Kutinana) 獨立製作 iOS 1.10 第三方移植版。**

**iOS 安裝方式**

除了 **IPA 側載安裝**，移植作者也提供了 **TestFlight 公開測試版**。使用免費 Apple 個人開發者帳號側載的提督，可以透過 TestFlight 免去每 7 天重新簽署的步驟，也方便接收後續測試版更新。

- **測試有效期**　每個測試組建自開發者上傳當天起最多可使用 **90 天**。剩餘時間可在 TestFlight 中查看，請在到期前留意移植作者發布的更新。
- **測試名額**　TestFlight 外部測試最多可容納 **10,000 人**。開放名額與是否仍可加入，請以邀請頁當時的狀態為準。
- **安裝方式**　先從 App Store 安裝 Apple 官方的 **TestFlight**，再開啟下方連結加入測試並安裝。

**[加入 iOS 版 TestFlight 公開測試](https://testflight.apple.com/join/WWU4StEm)**

iOS 移植版的功能、相容性及後續更新，請以移植作者的說明與實際發布的版本為準。

## 一、新增功能與主要改進

### 1. Android 新增 Kanxy 魔改支援

Yahagi 可透過 Kanxy 的 VPN 或本機 HTTP 代理載入遊戲資源。若在遊戲途中切換連線，需要重新整理的操作會等到遊戲回到前景，並確認已回到母港後再執行。

**首次使用 Kanxy 魔改時，請先設定 Kanxy，再設定 Yahagi。**

1. **選取魔改包。** 在 Kanxy 開啟「魔改設定」，啟用魔改並下載或勾選要使用的資源包。建議同時啟用 Kanxy 內建的資源快取。若 Kanxy 提示安裝憑證，請依畫面指示操作。
2. **啟用 HTTP 代理。** 在 Kanxy 開啟 HTTP 代理，記下顯示的監聽位址與連接埠。若兩個應用程式裝在同一支手機，請在 Yahagi 的位址欄填入 `127.0.0.1`，連接埠則填入 Kanxy 顯示的數值。
3. **連接 Yahagi。** 開啟「設定 → 網路與連線」，選擇「HTTP 代理」，填入位址及連接埠後，點選「套用設定並重新載入遊戲」。Yahagi 的原版資源快取平時可選「暫存快取」，Kanxy 圖片另有獨立快取。連接 Kanxy 期間會暫停預先下載原版資源。

**日後更換 Kanxy 魔改包**

先在 Kanxy 勾選新包並停用要替換的舊包，再開啟 Yahagi 的「設定 → 資料管理」，在「遊戲資源本機快取」中點選「清除 Kanxy 快取並重新載入遊戲」。若回到標題畫面，再點選 **GAME START**。繼續使用同一套魔改時，直接進入遊戲即可。

**同時使用 Kanxy 與 Yahagi 本機魔改**

若兩邊都替換了同一張圖片，會優先顯示 Yahagi 本機包的圖片。若想顯示 Kanxy 的版本，請先到「Yahagi → 工具箱 → 魔改」停用對應資源，點選「套用並重新整理遊戲」，再依上述更換 Kanxy 魔改包的步驟操作。

### 2. 新增「出擊經驗」，可逐艦查看經驗與 MVP 次數

- 一般與高畫質版面均可顯示「出擊經驗」簡報。出擊或演習結算後，可查看每艘艦獲得的經驗、等級進度與 MVP 次數。聯合艦隊會分別列出主力艦隊與護衛艦隊。
- 航海日誌新增「經驗」頁面，可回顧每次出擊和演習的艦隊與各艦明細。若想長期統計練等成果，可在簡報中開啟目前帳號的「總累計」，累計經驗與 MVP 次數。此選項預設關閉，航海日誌仍會獨立儲存經驗記錄。
- 記錄備份現已包含航海日誌的經驗記錄，也相容於舊版備份。資料不完整時會標示「部分記錄」。

### 3. 編隊簡報新增運輸量，艦隊狀態更容易辨認

- 編隊簡報可同時查看**一般運輸量與戰車運輸量（TP）**。點開詳情即可比較 S 勝與 A 勝的預估值。聯合艦隊會列出第一、第二艦隊各自貢獻的運輸量，並在適用時列出鬼怒改二的加成。編成圖與編成記錄也可查看運輸量。
- 艦隊標籤以顏色區分出擊、演習、遠征及待補給等狀態。遠征艦隊回港後，會等到收到各艦最新的燃料與彈藥資料，再判斷是否需要補給。艦娘中破或大破時，編隊簡報與艦娘詳情也會顯示受損立繪。

### 4. 修正遊戲內漢化包相容性問題，支援從 ZIP 更新

修正切換漢化包後仍顯示舊字型的問題。在「工具箱 → 魔改」匯入支援的漢化 ZIP，即可依包內內容替換遊戲介面圖片與字型，並翻譯任務標題、任務說明、遊戲文字與 BGM 曲名。**可直接匯入 `Kancolle_to_CHS` v1.4.0 的發布版 ZIP**，匯入前可先查看辨識到的資源。[Kancolle_to_CHS 發布頁](https://bbs.nga.cn/read.php?tid=44139718)

漢化包或立繪包推出新版時，可在已安裝資源包的詳情中選擇「從 ZIP 更新」，預覽新增與移除的資源。既有資源會保留原本的勾選狀態，資源包的啟用狀態與優先順序也會保留。新增且支援的資源預設勾選，確認後點選「套用並重新整理遊戲」即可。

Android 相簿也會略過共用魔改目錄中的素材，減少艦娘立繪出現在系統相簿的情況。

### 5. 新增「編隊資訊同步」

在「設定 → 出擊與戰鬥 → 未卜先知 → 編隊資訊同步」中，可選擇編隊簡報更新艦娘耐久與損管消耗的時機。

- **即時同步（預設）**　收到戰鬥資料後立即更新，可在戰鬥途中查看最新狀態。
- **結算同步**　等本場戰鬥結算後再更新，方便跟著遊戲的結算節奏查看艦隊狀態。

### 6. 新增「啟動檢查」，預設開啟

進入遊戲時會依序顯示「準備連線」「入口網頁」「啟動遊戲」三個階段。若載入停滯，可繼續等待或重新載入。連線失敗時，可查看並複製失敗階段、主機與錯誤碼，也可直接關閉提示。

啟動檢查預設開啟，可在「設定 → 遊戲執行」中關閉或重新開啟。

### 7. 任務中心顯示符合編成條件的艦隊

任務清單會醒目顯示遊戲伺服器回報的進度，例如 **50% 或 80%**。點開詳情後，伺服器進度會顯示在本機計數上方，方便對照遊戲已確認的進度與 Yahagi 記錄的次數。

對於可判斷編成條件的任務，詳情會列出目前第一至第四艦隊中符合條件的艦隊，方便選隊出擊。本次也修正了部分出擊與演習次數混計、聯合艦隊護衛艦判定，以及 Boss 節點辨識的問題。

### 8. 出擊、遠征與操作結果提醒可分項設定

頂端通知新增 **12 個獨立開關**。可保留關心的大破、補給與容量提醒，也可單獨關閉開發、改修、演習經驗或任務達成等通知。

進入出擊或遠征頁面時，Yahagi 會依設定提示相關艦隊的大破及油彈待補給情況。派出遠征後，若目前編成未滿足已知的成功條件，會提示本次遠征「可能失敗」。

## 二、修正與操作體驗改善

- **戰鬥預報與戰鬥記錄**　「未卜先知」可分別設定是否顯示海域小地圖、敵艦預覽與預測結果。戰鬥記錄新增空母夜襲 CI、多種驅逐艦夜戰 CI、瑞雲立體攻擊與海空立體攻擊的辨識，也修正了部分聯合艦隊夜戰特殊攻擊記在錯誤艦娘名下的問題。
- **遊戲畫面與操作**　遊戲畫面會維持原比例，在頂端列下方置中顯示。拖曳分割畫面、旋轉裝置及切換全螢幕後，縮放與觸控位置更準確，暫時叫出系統列時的畫面晃動也有所減少。另改善了滑鼠滾輪反應，以及返回前景或重建遊戲畫面後的靜音狀態還原。
- **簡報與工具箱**　入渠簡報將燃料、鋼材消耗及預計完成時間放在一起。切換頁面或旋轉螢幕後，海域查詢會保留地圖縮放與敵艦詳情。遊戲內功能區的顯示選項改為分組排列，在資料管理頁即可檢查海域、敵艦、任務、改修及字幕資料的更新。
- **語言與提示**　依簡體中文原文校訂繁體中文、日文、英文與韓文，明確區分「已裝備損管」與「損管已發動」，並統一艦隊最低士氣等用語。戰前敵艦預覽、魔改資源庫掃描與備份還原時的提示，也會隨所選語言顯示。

## 三、使用提醒

- 遊戲內漢化需要自行匯入資源包。
- 運輸量依目前的編成與裝備估算，戰車運輸採用 2026 年夏季活動的規則。實際扣除的 TP、任務達成與遠征結果，請以遊戲內結算為準。
