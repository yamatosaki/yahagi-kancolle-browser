今回のアップデートでは、**Kanxy の MOD** に対応し、**「出撃経験値」と艦隊の輸送量（TP）表示** を追加しました。また、**ゲーム内の中国語化パックの互換性の問題** を修正し、スマートフォン、タブレット、折りたたみ端末での操作性を改善しました。

Android 版は、**v1.0.9 およびこれまでに公開した v1.10 Beta から直接上書きアップデートできます**。アプリ内のデータを引き継ぐため、旧バージョンをアンインストールせずにインストールしてください。

**GitHub ID [@Kutinana](https://github.com/Kutinana) さんが iOS 1.10 移植版を制作してくださったことにも感謝します。このバージョンは第三者が独自に移植・制作したものです。**

**iOS のインストール方法について：**

従来の **IPA のサイドロードによるインストール** に加え、移植版の作者から **TestFlight の公開テスト版** も提供されています。無料の Apple 個人開発者アカウントを使ってサイドロードしている方は、TestFlight からインストールすることで、7 日ごとの再署名の手間を省けます。その後のテスト版の更新も受け取りやすくなります。

- **テストの有効期間：** TestFlight の各テストビルドは、開発者がアップロードした日から最長 **90 日間** 利用できます。具体的な残り期間は、TestFlight に表示される有効期限を確認してください。期限が切れる前に、移植版の作者による次の更新をご確認ください。
- **テスト参加枠：** TestFlight の外部テストは最大 **10,000 人** に対応しています。実際の募集枠と参加できるかどうかは、その時点の招待ページの状態によります。
- **インストール方法：** まず App Store から Apple 公式の **TestFlight** をインストールし、下記のリンクからテストに参加してインストールしてください。

**TestFlight 公開テストへの参加：[iOS 版の公開テストに参加する](https://testflight.apple.com/join/WWU4StEm)**

iOS 移植版の具体的な機能、互換性、今後の更新については、移植版の作者による説明と実際のバージョンをご確認ください。

## 1. 新機能と主な改善

### 1. Android 版で Kanxy の MOD に対応

Kanxy の VPN またはローカル HTTP プロキシを経由して、Yahagi でゲームリソースを読み込めるようになりました。プレイ中に接続を切り替えた場合、再読み込みが必要な処理は、ゲームがフォアグラウンドに戻り、母港にいることを確認してから実行します。

**初めて Kanxy の MOD を使うときは、先に Kanxy を設定してから Yahagi を設定してください。**

1. **MOD パックを選びます。** Kanxy の「魔改设置」（MOD 設定）で MOD を有効にし、使いたいパックをダウンロードするか、チェックを入れます。Kanxy のリソースキャッシュも併せて有効にすることをおすすめします。証明書のインストールを求められた場合は、Kanxy の案内に従ってください。
2. **HTTP プロキシを有効にします。** Kanxy で HTTP プロキシを有効にし、表示された待受アドレスとポートを控えます。両方のアプリを同じスマートフォンにインストールしている場合は、Yahagi にアドレス `127.0.0.1` と、Kanxy に表示されたポートを入力します。
3. **Yahagi を接続します。** 「設定 → ネットワークと接続」で「HTTP プロキシ」を選び、アドレスとポートを入力して「設定を適用してゲームを再読み込み」をタップします。通常、元のゲームリソースには「一時キャッシュ」で十分です。Kanxy の画像には専用のキャッシュがあります。Kanxy との併用中は、元のゲームリソースの事前ダウンロードを一時停止します。

**Kanxy の MOD パックを変更するとき**

先に Kanxy で新しいパックにチェックを入れ、入れ替える古いパックを無効にします。次に Yahagi の「設定 → データ管理」を開き、「ゲームリソースのローカルキャッシュ」で「Kanxy キャッシュを削除してゲームを再読み込み」をタップします。タイトル画面に戻ったら **GAME START** をタップしてください。同じパックを使い続ける場合は、そのままゲームを開始できます。

**Kanxy と Yahagi のローカル MOD を併用するとき**

同じ画像を両方で置き換えた場合は、Yahagi のローカルパックの画像を優先します。その画像に Kanxy の MOD を使いたい場合は、まず「Yahagi → ツールボックス → MOD」で該当リソースを無効にし、「適用してゲームを再読み込み」をタップしてください。その後、上記のパック変更手順に従います。

### 2. 「出撃経験値」で艦娘ごとの獲得経験値と MVP 回数を確認

- 通常レイアウトと HD レイアウトのどちらでも「出撃経験値」を表示できます。出撃・演習の結果を受け取ると、艦娘ごとの獲得経験値、次のレベルまでの進み具合、MVP 回数を確認できます。連合艦隊では主力艦隊と護衛艦隊を分けて表示します。
- 航海日誌に **「経験値」** タブを追加しました。出撃・演習ごとに艦隊と各艦の明細を振り返れます。育成の成果を長期的に集計したい場合は、「出撃経験値」で現在のアカウントの「累計」を有効にすると、経験値と MVP 回数を積算できます。「累計」は初期設定ではオフです。航海日誌の経験値記録は、この設定にかかわらず保存されます。
- 記録のバックアップに航海日誌の経験値記録を含めました。以前のバージョンのバックアップも引き続き利用できます。データが欠けている記録には「一部記録」と表示します。

### 3. 編成情報に輸送量を追加し、艦隊の状態を見やすく改善

- 編成情報で **通常輸送と戦車輸送の輸送量（TP）** を同時に確認できます。詳細を開くと、S 勝利と A 勝利それぞれの見込み値を比較できます。連合艦隊では第一・第二艦隊それぞれの寄与分と、該当する場合には鬼怒改二の内蔵補正も表示します。輸送量は編成画像と編成記録でも確認できます。
- 艦隊タブを色分けし、出撃中、演習中、遠征中、要補給などの状態を判別しやすくしました。遠征から帰投した艦隊は、各艦の最新の燃料・弾薬データを受け取ってから補給の要否を判定します。編成情報と艦娘詳細では、中破・大破の状態に応じて損傷時の立ち絵を表示します。

### 4. ゲーム内の中国語化パックの互換性を改善し、ZIP からの更新に対応

中国語化パックを切り替えた後も旧フォントが表示される問題を修正しました。「ツールボックス → MOD」で対応する中国語化パックの ZIP をインポートすると、パックの内容に応じてゲーム画面の画像とフォントを置き換え、任務名・任務説明・ゲーム内テキスト・BGM の曲名を中国語化できます。**`Kancolle_to_CHS` v1.4.0 の配布 ZIP をそのままインポートできます。** 認識されたリソースはインポート前のチェックで確認できます。

**[Kancolle_to_CHS 配布ページ](https://bbs.nga.cn/read.php?tid=44139718)**

中国語化パックや立ち絵パックに新しいバージョンが出たら、インストール済みパックの詳細で **「ZIPから更新」** を選んでください。追加・削除されるリソースを事前に確認できます。既存のリソースは選択状態を引き継ぎ、パックの有効・無効と優先順位も保持します。新たに追加された対応リソースには、初めからチェックが入ります。内容を確認し、「適用してゲームを再読み込み」をタップすると切り替わります。

Android のギャラリーでは共有 MOD フォルダー内の素材を読み飛ばすようにし、艦娘の立ち絵が端末の写真一覧に表示されにくくなりました。

### 5. 「艦隊情報の同期」を追加

「設定 → 出撃と戦闘 → 戦闘予測 → 艦隊情報の同期」で、編成情報に各艦の耐久とダメコンの消費を反映するタイミングを選べます。

- **即時同期（初期設定）**　戦闘データを受信した時点で更新します。戦闘中も最新の状態を確認できます。
- **戦闘結果で同期**　その戦闘の結果を受信してから更新します。ゲームの結果表示と同じタイミングで艦隊の状態を確認したいときに選んでください。

### 6. 「起動チェック」を追加し、初期設定で有効に

ゲームを開始すると、「接続準備」「起動画面」「ゲーム起動」の順に進捗を表示します。読み込みが途中で止まった場合は、そのまま待つか、再読み込みするかを選べます。接続に失敗した場合は、失敗した段階、ホスト、エラーコードを確認・コピーできます。案内をそのまま閉じることもできます。

起動チェックは初期設定で有効です。「設定 → ゲーム動作」で無効化・再有効化できます。

### 7. 任務センターに編成条件を満たす艦隊を表示

任務一覧で、**50% や 80%** など、ゲームサーバーから受け取った進捗を強調表示します。任務詳細ではサーバー側の進捗をローカルのカウントの上に表示し、ゲーム側で確認された進捗と Yahagi が記録した具体的な回数を見比べられます。

編成条件の判定に対応した任務では、現在の第一～第四艦隊のうち条件を満たす艦隊を詳細に表示します。出撃する艦隊を選ぶ際に確認できます。また、一部の任務で出撃と演習の回数が混同される問題や、連合艦隊の護衛艦の判定、ボスマスの識別に関する問題を修正しました。

### 8. 出撃・遠征の警告や操作結果の通知を個別に設定可能に

画面上部の通知に **12 項目の個別スイッチ** を追加しました。大破、補給、保有枠の警告を有効にしたまま、開発、改修、演習経験値、任務達成などの通知を個別に無効にできます。

出撃・遠征画面を開くと、設定に応じて対象艦隊の大破艦や燃料・弾薬の補給漏れを知らせます。遠征に出した後、その艦隊の編成が判明している成功条件を満たしていない場合は、今回の遠征が「失敗する可能性があります」と通知します。

## 2. 不具合の修正と使い勝手の改善

- **戦闘予測と戦闘記録**　「戦闘予測」では海域ミニマップ、敵艦予測、予測結果の表示を個別に切り替えられます。戦闘記録では空母夜襲カットイン、複数の駆逐艦夜戦カットイン、瑞雲立体攻撃、海空立体攻撃を識別できるようにしました。また、連合艦隊の夜戦で一部の特殊攻撃が別の艦娘の攻撃として表示される問題を修正しました。
- **ゲーム画面と操作**　上部バーの下でゲーム画面の縦横比を保ち、中央に表示します。分割画面の境界をドラッグしたとき、画面を回転したとき、全画面表示を切り替えたときの拡大・縮小とタッチ位置のずれを改善し、システムバーを一時表示したときの画面の揺れを抑えました。マウスホイールの反応も改善し、アプリがフォアグラウンドに戻ったときやゲーム画面が再生成されたときに、ミュート状態を正しく復元するようにしました。
- **サマリーとツールボックス**　入渠のサマリーで、消費する燃料・鋼材と完了予定時刻をまとめて表示します。海域検索では、ページを切り替えたり画面を回転したりしても、マップの拡大率と敵艦の詳細表示を保持します。ゲーム内の機能エリアの表示設定をグループ別に整理しました。データ管理ページでは、海域・敵艦・任務・改修・字幕の各データの更新を直接確認できます。
- **言語と案内表示**　簡体字中国語を基準に繁体字中国語、日本語、英語、韓国語の訳文を見直しました。ダメコンが「装備されている」状態と「発動した」状態を明確に区別し、艦隊の「最低コンディション」などの用語を統一しました。戦闘前の敵艦予測、MOD ライブラリのスキャン、バックアップからの復元で表示する案内も、選択した言語に従います。

## 3. ご利用にあたって

- ゲーム内の中国語化を利用するには、ご自身でリソースパックをインポートしてください。
- 輸送量は現在の編成と装備から求めた見込み値です。戦車輸送には 2026 年夏イベントのルールを使用します。実際に減少した TP、任務の達成状況、遠征の成否はゲーム内の結果をご確認ください。
