v1.0.8 と比べ、今回は **MOD リソースの管理、艦娘ボイスの字幕、より豊富な画面のカスタマイズ機能** を中心に追加しました。あわせて **「戦闘予測」に海域ミニマップ** を追加し、任務センター、戦闘通知、戦果集計、記録のバックアップを幅広く改善しました。スマートフォン、タブレット、折りたたみ端末での使い勝手も引き続き改善しています。

Android 版は、**v1.0.8 および先行公開された v1.0.9 Beta から直接上書きアップデートできます**。インストール前に旧バージョンをアンインストールする必要はありません。アプリ内データの消失を防ぐため、旧バージョンをアンインストールしないでください。

**GitHub ID [@Kutinana](https://github.com/Kutinana) さんが iOS 1.0.9 移植版を制作してくださったことにも感謝します。このバージョンは第三者が独自に移植・制作したものです。**

**iOS のインストール方法について：**

従来の **IPA のサイドロードによるインストール** に加え、移植版の作者から **TestFlight の公開テスト版** も提供されています。無料の Apple 個人開発者アカウントを使ってサイドロードしている方は、TestFlight からインストールすることで、7 日ごとの再署名の手間を省けます。その後のテスト版の更新も受け取りやすくなります。

- **テストの有効期間：** TestFlight の各テストビルドは、開発者がアップロードした日から最長 **90 日間** 利用できます。具体的な残り期間は、TestFlight に表示される有効期限を確認してください。期限が切れる前に、移植版の作者による次の更新をご確認ください。
- **テスト参加枠：** TestFlight の外部テストは最大 **10,000 人** に対応しています。実際の募集枠と参加できるかどうかは、その時点の招待ページの状態によります。
- **インストール方法：** まず App Store から Apple 公式の **TestFlight** をインストールし、下記のリンクからテストに参加してインストールしてください。

**TestFlight 公開テストへの参加：[iOS 版の公開テストに参加する](https://testflight.apple.com/join/WWU4StEm)**

iOS 移植版の具体的な機能、互換性、今後の更新については、移植版の作者による説明と実際のバージョンをご確認ください。

## 一、新機能・主な改善

### 1. MOD リソース管理の追加

ツールボックスに **「MOD」** 機能を追加しました。対応する MOD リソースパックを端末内にインポートして管理し、ゲーム内の艦娘の立ち絵、ボイス、対応する座標設定を置き換えられます。

- ZIP 形式の MOD パックのインポートに対応しました。端末内のリソースフォルダーを指定し、その中の ZIP や展開済みフォルダーをスキャンして、一括でインポートすることもできます。
- 通常立ち絵、中破立ち絵、座標、ボイスのリソースを個別に選択でき、複数のパックの有効・無効と優先順位を管理できます。
- 変更後は **「適用してゲームを再読み込み」** からまとめて適用できます。まだ適用していない変更は取り消せます。
- インポート、スキャン、適用中は処理の進捗を表示し、現在の状態を確認しやすくしました。
- 適用済みの MOD の艦娘アイコンを、艦隊サマリー、艦娘詳細、保有一覧にも反映でき、ゲーム画面とアプリ内の艦娘表示を揃えやすくしました。
- MOD を無効にしたり、元のリソースに戻したりできます。その際も、従来のログイン情報、通常のゲームキャッシュ、設定、記録は保持されます。

MOD リソースは、対応する形式とパスに従う必要があります。複数のパックでリソースが重複する場合は、設定した優先順位に従って処理します。具体的な対応状況と未対応の項目は、インポート前のチェックで案内します。

### 2. 艦娘ボイス字幕の追加

**「艦娘ボイス字幕」** 機能を追加しました。ゲームで艦娘のボイスが再生された際に対応するセリフを表示し、内容を読み取りやすくします。

- **簡体字中国語、繁体字中国語、日本語、英語、韓国語** の 5 言語に対応しています。
- 字幕言語はアプリの表示言語から独立しており、好みに合わせて個別に選択できます。
- 文字サイズは小・中・大の 3 段階から選べます。画面のロックを解除すると、ドラッグハンドルを使って字幕の位置を調整できます。
- 字幕の位置は保存され、機能を再び有効にしたときやウィンドウを調整した後も、その位置を引き続き利用できます。
- 長いセリフはボイスの長さに応じてページを分けて表示し、文字がゲーム画面からはみ出しにくくしました。
- 字幕データを内蔵し、設定から更新を確認できます。字幕を有効にしている間は、定期的にデータの更新も確認します。

字幕は初期設定では無効です。設定から手動で有効にしてください。字幕データの更新でダウンロードするのはセリフと名称のテキストであり、ゲームの音声ファイルは含まれません。

### 3. 画面のカスタマイズとスマートフォン向けレイアウトの改善

外観や表示方法の選択肢を増やし、スマートフォン、小さなウィンドウ、大画面端末で、使い方に合わせて調整しやすくしました。

**ミニマル表示とタブ式サマリーの追加：**

- 従来の通常・コンパクトに加え、**「ミニマル」** 表示を追加しました。操作部品が占めるスペースを減らし、小さな画面での情報表示を改善します。
- よりすっきりしたフラットな情報パネルのスタイルを追加しました。
- 通常レイアウトのサマリーに **「タブ式」** 表示を追加しました。タブで項目を切り替えられ、上下のスクロールを減らせます。従来の折りたたみ式も引き続き利用できます。

**テーマとフォントのカスタマイズの追加：**

- 従来のダークテーマに加え、**「シーソルト」と「スカイブルー」** の 2 種類のライトテーマを追加しました。
- TTF・OTF フォントのインポートに対応し、プレビュー、適用、標準フォントに戻す機能を用意しました。
- 画面の表示密度と文字サイズを個別に設定できます。文字サイズは、システム設定に従うほか、小・中・大から選べます。

**画面サイズ・形状への対応改善：**

- カメラ、ノッチ、パンチホールを避ける設定を追加し、端末に合わせて余白を調整できるようにしました。
- 分割画面、高さの低いウィンドウ、幅の狭い画面、文字を拡大した場合のレイアウトを改善し、内容の見切れや重なり、操作領域の混雑を軽減しました。

### 4. 英語・韓国語の表示言語を追加

従来の簡体字中国語、繁体字中国語、日本語に加え、**英語と韓国語の画面表示** に対応しました。

- 艦娘、装備、艦種、装備分類などの名称の英語・韓国語表示を追加しました。
- 艦隊、保有一覧、任務、開発、改修、経験値計算などのページに、対応する名称の翻訳を反映しました。
- 関連する検索では、対応済みの原名と訳名の両方を認識し、各言語で資料を探しやすくしました。
- 翻訳データは更新できます。対応する訳名がない項目は、引き続き原名で表示します。

名称の翻訳は Yahagi の補助画面に適用されます。ゲーム内データ、リソースのパス、エクスポートするデータの元の内容は変更しません。

### 5. 任務センターと進捗追跡の強化

任務情報の検索と端末内での進捗追跡を引き続き改善し、任務の検索、条件の確認、前提・後続任務の整理をしやすくしました。

- 検索と絞り込みを再整理し、キーワード、種類、周期、状態などの条件をまとめて設定できるようにしました。適用前に該当件数を確認できます。
- 任務番号による検索を改善し、表示言語の艦娘名や装備名を使った関連任務の検索にも対応しました。
- 任務詳細を **条件と進捗、報酬、関連任務** のタブに分け、資源報酬、テキストで示される報酬、選択報酬の表示を補いました。
- 前提任務を展開してさかのぼれるようにしました。関連任務を確認した後は元の任務に戻れ、任務のつながりを整理しやすくなりました。
- 内蔵するローカル進捗ルールを **432 任務** に拡充し、設定から個別にルールの更新確認と更新ができるようにしました。
- 一部の艦船、艦種、海域マス、随伴艦の条件を修正し、周期ごとのリセット、進捗の保存、アップデート後のルール保持を改善しました。

ローカル進捗は、アプリが実際に観測できたデータに基づいて加算します。一部の任務では引き続き参考値のカウントとなります。任務の達成状況や報酬を受け取れるかどうかは、ゲーム内の状態を確認してください。

### 6. 「戦闘予測」に海域ミニマップを追加

「戦闘予測」に **海域ミニマップ** を追加しました。出撃中に現在の海域のマスとルートを直接確認でき、戦闘情報とあわせて進行状況を把握しやすくなりました。

- 取得できた出撃データに基づき、現在のマスと今回の出撃で通過したルートを表示します。
- ミニマップをリアルタイムの戦闘情報と一緒に表示し、ツールボックスの検索ページに切り替えずに確認できます。
- 展開・折りたたみに対応し、情報欄の幅に合わせて表示することで、小画面端末でのスペース占有を抑えます。
- マスのラベルとルート線の配置を調整し、文字の重なりやルートの読み違いを減らしました。

ミニマップは、取得済みのゲームデータと海域データに基づいて表示します。データを利用できない場合や取得が不完全な場合は、表示内容が欠けることがあります。ゲーム画面とあわせて確認してください。

### 7. 大破通知と戦闘情報の改善

従来の戦闘補助と大破通知をもとに、ダメコン情報、通知のタイミング、ゲーム内での通知表示をさらに改善しました。

- 大破通知で対象の艦娘をまとめて表示し、通常の装備スロットと補強増設にある **残りの応急修理要員・応急修理女神** を確認します。
- ダメコン未装備、残りのダメコンあり、状態を確認できない場合を区別し、確認しやすくしました。
- **戦闘結果後の通知、進撃後の通知** を個別に選べるほか、両方を有効にできます。
- 「常に確認」と「スマート通知」に対応しました。スマート通知では、残りのダメコンとデータの信頼性に応じて、上部通知と確認ダイアログを使い分けます。
- 今回の出撃中の通知音をミュートでき、通知からゲーム全体の手動再読み込みやフレームの再読み込みも行えます。
- 「戦闘予測」に現在のマスでのダメコン発動マークを追加し、今回の戦闘でのダメコン使用状況を確認しやすくしました。
- ギミック解除／装甲破砕に関する通知を追加しました。ゲームから返されるギミック解除や弱体化の合図を検出した際に、ダイアログや上部通知で知らせます。

あわせて、Android のネイティブゲーム画面での大破・新艦娘などの通知表示を改善し、通知がゲーム画面に隠れる問題や、ダイアログ表示後に画面が停止する問題などを軽減しました。

### 8. 戦果集計と記録のバックアップの改善

戦果記録、カレンダー、目標計算の精度を引き続き改善し、記録のバックアップ対象も拡充しました。

- 経験値、EO、任務報酬による戦果記録を最適化し、一部の二重計上、更新の遅れ、月末の月をまたぐ記録の帰属に関する問題を修正しました。
- 任務の戦果報酬の判定を改善し、別の報酬を選んだ際に戦果が誤って加算されるケースを減らしました。
- 戦果カレンダー、今日の残り目標、1 日あたりの必要戦果の計算を修正し、ランキング更新や計画変更による二重の差し引きを減らしました。
- 基礎戦果の入力と再設定を戦果情報ページにまとめ、確認・調整しやすくしました。
- 記録のバックアップに **現在のアカウントの戦果記録** を追加し、従来の航海日誌・編成記録に加えて、より多くの記録を保存できるようにしました。
- バックアップの統合、保存、復元、中断後の処理を強化しました。既存のバックアップファイルにも引き続き対応します。

## 二、修正・使い勝手の改善

- **ゲーム画面・ブラウズ：** OOI のゲーム入口の判定とネイティブ画面への対応を改善し、タブレット、分割画面、高さの低いウィンドウでの拡大縮小、見切れ、表示の復元に関する問題を軽減しました。
- **ダイアログ・再読み込み：** 一部のダイアログや再読み込み操作でゲーム画面が停止する問題を修正し、通知表示中のゲーム画面の再生や操作を改善しました。
- **戦闘予測：** データ取得が中断した後の状態復元と未確認状態の表示を改善し、戦闘情報の同期と更新を整えました。
- **通知・バックグラウンド：** バックグラウンドでの動作維持と復帰の仕組みを最適化し、端末の再起動、アプリのアップデート、関連する権限の変更後に、有効な時刻指定の通知を復元するようにしました。
- **航海日誌：** 遠征、建造、開発、除籍記録の絞り込みとページ分けを改善し、古い記録が絞り込みの対象にならない問題や、更新後に閲覧位置が失われる問題を軽減しました。
- **ツールボックス・データ更新：** 開発、改修、遠征、経験値計算などのページで、名称表示、絞り込み操作、狭い画面への対応を改善しました。一部のデータ処理による画面の引っかかりも軽減しました。
- **画面・設定：** アプリアイコンと上部のロゴを更新し、設定の分類を再整理しました。テーマ、切り替えボタン、絞り込み操作部品の表示スタイルも統一しました。
- **その他の修正：** 一部のプロキシルーティング、キャッシュの復元、アカウント切り替え、記録保存の問題を修正し、全体の動作安定性を引き続き改善しました。

## 三、利用上の注意

- **上書きアップデート時に旧バージョンをアンインストールする必要はありません。** 端末の変更、アプリのアンインストール、アプリデータの削除を予定している場合は、事前に残したい記録をエクスポートし、バックアップファイルが保存されていることを確認してください。
- MOD 機能は、要件を満たすリソースパックのみ対応しています。インポート前のチェック結果を確認してからゲームに適用してください。元のリソースパックとフォントファイルは、ご自身でも保管することをお勧めします。
- ボイス字幕の表示には、ゲームで対応するボイス再生イベントが発生する必要があります。ゲームのボイスを完全に無効にしている場合、字幕が表示されないことがあります。また、一部の古いシステム WebView は更新が必要になる場合があります。
- ローカルの任務進捗、戦果の見積もり、海域ミニマップ、戦闘通知は、いずれも情報確認を補助するものです。最終的な状態はゲーム内の実際の表示を確認してください。
- 大破通知は、すでに送信された進撃リクエストを止めることはできず、自動で撤退する機能もありません。ダメコンを装備していても、ゲーム内の状態確認を省略しないでください。
- ギミック解除／装甲破砕の通知は、ゲームから返される関連する合図を知らせるものです。イベントのギミック攻略全体を案内する機能ではなく、装甲破砕の全条件が達成されたことを示すものでもありません。
- 記録のバックアップは現在、航海日誌、編成記録、戦果記録が対象です。アプリのデータと設定をすべて移行するものではありません。
- バックグラウンド通知は、引き続きシステムの権限、省電力設定、端末側のバックグラウンド管理の影響を受けます。
