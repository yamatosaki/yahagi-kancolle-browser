# ヤハギ v1.0.9 正式版更新說明

相較於 v1.0.8，本次更新重點加入了 **魔改資源管理、艦娘語音字幕，以及更豐富的介面個人化選項**。同時新增了 **「未卜先知」海域小地圖**，並對任務中心、戰鬥提醒、戰果統計與記錄備份進行了多項改進，持續改善手機、平板與摺疊螢幕裝置上的使用體驗。

Android 版支援從 **v1.0.8 及先前發布的 v1.0.9 Beta 版本直接覆蓋升級**。安裝前無須解除安裝舊版，且請勿自行解除安裝，以免造成應用程式內資料遺失。

**也感謝 GitHub ID [@Kutinana](https://github.com/Kutinana) 同志製作了 iOS 1.0.9 移植版本；該版本由第三方自行移植與製作。**

**iOS 安裝方式補充：**

除了原有的 **IPA 側載安裝**，移植作者也提供了 **TestFlight 公開測試版**。對於使用免費 Apple 個人開發者帳號側載的使用者，透過 TestFlight 安裝可以省去每 7 天重新簽署的麻煩，也方便後續接收測試版本更新。

- **測試有效期：** 每個 TestFlight 測試組建自開發者上傳之日起，最長可使用 **90 天**；實際剩餘時間以 TestFlight 顯示的有效期為準。到期前請留意移植作者提供的後續更新。
- **測試名額：** TestFlight 外部測試最多支援 **10,000 人**，實際開放名額及能否加入，以邀請頁面當時的狀態為準。
- **安裝方式：** 先在 App Store 安裝 Apple 官方的 **TestFlight**，再透過下方連結加入測試並安裝。

**TestFlight 公開測試入口：[點此加入 iOS 版公開測試](https://testflight.apple.com/join/WWU4StEm)**

iOS 移植版的具體功能、相容性與後續更新，以移植作者的說明及實際版本為準。

## 一、新增功能與主要改進

### 1. 新增魔改資源管理

工具箱新增 **「魔改」** 功能，可在裝置本機匯入及管理支援的魔改資源包，替換遊戲中的艦娘立繪、語音及相應的座標設定。

- 支援匯入 ZIP 格式魔改包，也可指定本機資源資料夾，掃描其中的 ZIP 或已解壓縮目錄後批次匯入。
- 支援分別選擇一般立繪、中破立繪、座標及語音資源，並管理多個資源包的啟用狀態與優先順序。
- 修改完成後，可透過 **「套用並重新整理遊戲」** 統一套用；尚未套用的修改支援取消。
- 匯入、掃描與套用時顯示處理進度，方便確認目前狀態。
- 支援將已套用的魔改頭像同步至編隊簡報、艦娘詳細資訊及持有一覽，讓遊戲畫面與軟體中的艦娘展示更加一致。
- 可關閉魔改或還原原版資源，並保留原有登入資訊、一般遊戲快取、設定與記錄。

魔改資源須符合支援的格式與路徑。不同資源包之間有資源覆蓋時，會依設定的優先順序處理；具體支援情況與不支援的項目會在匯入預檢中說明。

### 2. 新增艦娘語音字幕

新增 **「艦娘語音字幕」** 功能，可在遊戲播放艦娘語音時顯示對應台詞，方便閱讀與理解語音內容。

- 支援 **簡體中文、繁體中文、日語、英語和韓語** 五種字幕語言。
- 字幕語言獨立於應用程式介面語言，可依個人習慣單獨選擇。
- 提供小、中、大三種字級；解除介面鎖定後，可透過拖曳手柄調整字幕位置。
- 字幕位置會儲存，重新開啟功能或調整視窗後仍可沿用。
- 較長的台詞會依語音長度分頁顯示，減少文字超出遊戲畫面的情況。
- 內建字幕資料，並支援在設定中檢查更新；開啟字幕後，也會定期檢查資料更新。

字幕預設關閉，可在設定中手動開啟。字幕資料更新下載的是台詞與名稱文字，不包含遊戲語音檔案。

### 3. 介面個人化與手機配置升級

本次增加了更多外觀和顯示方式選項，讓手機、小視窗與大螢幕裝置能依使用習慣進行調整。

**新增極簡介面與分頁式簡報：**

- 在原有一般、緊湊檔位基礎上，新增 **「極簡」** 介面檔位，減少控制項佔用空間，改善較小螢幕上的資訊展示。
- 增加更簡潔的扁平資訊面板樣式。
- 一般配置下的簡報新增 **「分頁式」** 展示，可透過頁籤切換不同模組，減少上下捲動；也可繼續使用原有摺疊式展示。

**新增主題與字型自訂：**

- 在原版暗色外觀之外，新增 **「海鹽青」和「晴空藍」** 兩種淺色主題。
- 支援匯入 TTF、OTF 字型，並提供預覽、套用及還原預設字型功能。
- 介面顯示密度與文字大小可分別設定，字級支援跟隨系統及小、中、大檔位。

**完善螢幕適配：**

- 新增鏡頭、瀏海及挖孔避讓設定，可依裝置情況調整避讓距離。
- 改善分割畫面、低高度視窗、窄螢幕及文字放大後的配置，減少內容裁切、遮擋與操作區域擁擠的問題。

### 4. 新增英語與韓語介面

在原有簡體中文、繁體中文和日語基礎上，新增 **英語和韓語介面**。

- 補充艦娘、裝備、艦種及裝備類別等名稱的英韓顯示。
- 艦隊、持有一覽、任務、開發、改修、經驗計算等頁面接入相應的名稱翻譯。
- 相關搜尋支援識別已接入的原名與譯名，方便不同語言的使用者查找資料。
- 翻譯資料支援更新；尚無對應譯名的內容會繼續顯示原名。

名稱翻譯作用於 Yahagi 的輔助介面，不會改變遊戲內資料、資源路徑或匯出資料的原始內容。

### 5. 任務中心與進度追蹤強化

持續完善任務資料查詢與本機進度追蹤，讓查找任務、查看條件及安排前後置關係更加方便。

- 重新整合搜尋與篩選，將關鍵字、類型、週期和狀態等條件集中設定，套用前可預覽符合條件的數量。
- 完善任務編號查詢，並支援使用顯示語言中的艦娘、裝備名稱搜尋相關任務。
- 任務詳細資訊依 **條件與進度、獎勵、關聯任務** 分頁展示，補齊資源獎勵、文字獎勵及選擇獎勵的顯示。
- 前置任務支援展開追溯，查看關聯任務後可返回原任務，方便整理任務鏈。
- 內建本機進度規則擴充至 **432 個任務**，並支援在設定中獨立檢查及更新規則。
- 修正部分艦船、艦種、海域節點及同行艦條件，改善週期重設、進度儲存及升級後的規則保留。

本機進度依據應用程式實際觀察到的資料累計，部分任務仍僅提供參考計數；是否完成及能否領取獎勵，請以遊戲內狀態為準。

### 6. 「未卜先知」新增海域小地圖

「未卜先知」新增 **海域小地圖**，可在出擊過程中直接查看目前海域的節點與路線，方便搭配戰鬥資訊確認行進情況。

- 根據已擷取的出擊資料，顯示目前節點及本次出擊已經過的路線。
- 小地圖與即時戰鬥資訊放在一起，無須切換至工具箱查詢頁面。
- 支援展開和摺疊，並適配不同寬度的資訊欄，減少小螢幕裝置上的空間佔用。
- 調整節點標籤與航線配置，減少文字遮擋和線路誤讀。

小地圖依已取得的遊戲資料與海域資料顯示；資料暫時不可用或擷取不完整時，顯示內容可能不完整，請搭配遊戲畫面確認。

### 7. 大破提醒與戰鬥資訊改進

在原有戰鬥輔助與大破提醒基礎上，進一步完善損管資訊、提醒時機與遊戲內提示的呈現方式。

- 大破提醒合併列出相關艦娘，並檢查一般裝備欄及補強增設中的 **剩餘應急修理要員、應急修理女神**。
- 區分未攜帶損管、攜帶剩餘損管及狀態無法確認的情況，方便核對。
- 支援分別選擇 **結算後提醒、進擊後提醒**，也可同時開啟。
- 支援「始終確認」與「智慧提醒」；智慧提醒會依剩餘損管及資料可信度，選擇頂部提示或確認對話框。
- 支援本次出擊靜音，並在提醒中提供手動重新整理遊戲與框架重新整理的入口。
- 「未卜先知」增加本節點的損管發動標記，方便確認本次戰鬥中的損管使用情況。
- 新增解謎／削甲相關提示提醒，偵測到遊戲回傳的解謎或削弱訊號時，可透過對話框或頂部提示提醒。

同時改善大破、新艦等提示在 Android 原生遊戲畫面上的顯示，減少提醒被遊戲畫面遮擋、對話框出現後畫面凍結等問題。

### 8. 戰果統計與記錄備份完善

持續改善戰果記錄、日曆和目標計算的準確性，並擴充記錄備份的範圍。

- 最佳化經驗、EO 和任務獎勵的戰果記錄，修正部分重複入帳、延遲更新及月底跨月歸屬問題。
- 改善任務戰果獎勵識別，減少選擇其他獎勵時錯誤計入戰果的情況。
- 修正戰果日曆、今日剩餘目標及每日需求的計算，減少排名更新或計畫調整造成的重複扣減。
- 將基礎戰果的輸入與重設集中至戰果資訊頁，方便查看和調整。
- 記錄備份新增 **目前帳號的戰果檔案**，在原有航海日誌與編成記錄基礎上保留更多記錄。
- 加強備份合併、儲存、還原及中斷後的處理，持續相容既有備份檔案。

## 二、修正與體驗改善

- **遊戲畫面與瀏覽：** 完善 OOI 遊戲入口識別和原生畫面適配，改善平板、分割畫面與低高度視窗中的縮放、裁切及恢復問題。
- **對話框與重新整理：** 修正部分對話框及重新整理操作導致遊戲畫面卡住的問題，改善提示顯示期間的遊戲畫面播放與操作體驗。
- **未卜先知：** 改善擷取中斷後的狀態恢復與未確認狀態顯示，完善戰鬥資訊的同步與更新。
- **通知與背景：** 最佳化背景保持與恢復機制，並在裝置重新啟動、應用程式升級或相關權限變更後，恢復有效的排程提醒。
- **航海日誌：** 改善遠征、建造、開發和除籍記錄的篩選與分頁，減少舊記錄未參與篩選，或重新整理後瀏覽位置遺失的問題。
- **工具箱與資料更新：** 完善開發、改修、遠征、經驗計算等頁面的名稱顯示、篩選控制項及窄螢幕適配，減少部分資料處理造成的介面卡頓。
- **介面與設定：** 更新應用程式圖示與頂部標誌，重新整理設定分類，並統一主題、切換按鈕及篩選控制項的顯示樣式。
- **其他修正：** 修正部分代理路由、快取恢復、帳號切換及記錄儲存問題，持續改善整體運作穩定性。

## 三、使用提示

- **覆蓋升級時無須解除安裝舊版。** 若準備更換裝置、解除安裝應用程式或清除應用程式資料，請先匯出需要保留的記錄，並確認備份檔案已儲存。
- 魔改功能僅支援符合要求的資源包。請先查看匯入預檢結果，再套用至遊戲；建議自行保留原始資源包與字型檔案。
- 語音字幕需要遊戲產生對應的語音播放事件。完全關閉遊戲語音時，可能無法顯示字幕；部分較舊的系統 WebView 也可能需要更新。
- 本機任務進度、戰果估算、海域小地圖與戰鬥提示皆用於輔助查看，最終狀態請以遊戲內實際顯示為準。
- 大破提醒無法攔截已送出的進擊請求，也不會自動撤退；攜帶損管不代表可以忽略遊戲內狀態確認。
- 解謎／削甲提醒用於提示遊戲回傳的相關訊號，不提供完整活動機關攻略，也不代表所有削甲條件均已完成。
- 記錄備份目前包含航海日誌、編成記錄及戰果檔案，仍不屬於完整的應用程式資料與設定移轉。
- 背景提醒仍會受到系統權限、省電策略及裝置背景管理方式的影響。
