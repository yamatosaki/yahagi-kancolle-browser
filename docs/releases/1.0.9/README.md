Android 版支持从 **v1.0.8 及此前发布的 v1.0.9 Beta 版本直接覆盖升级**。安装前无需卸载旧版本，且请勿主动卸载，以免造成应用内数据丢失。

**并且感谢 GitHub ID [@Kutinana](https://github.com/Kutinana) 同志制作了 iOS 1.0.9 移植版本；该版本由第三方自行移植和制作。**

- **测试有效期：** 每个 TestFlight 测试构建自开发者上传之日起，最长可用 **90 天**；具体剩余时间以 TestFlight 中显示的有效期为准。到期前请留意移植作者提供的后续更新。
- **测试名额：** TestFlight 外部测试最多支持 **10,000 人**，实际开放名额及能否加入，以邀请页面当时的状态为准。
- **安装方式：** 先在 App Store 安装 Apple 官方的 **TestFlight**，再通过下方链接加入测试并安装。

**TestFlight 公开测试入口：[点击加入 iOS 版公开测试](https://testflight.apple.com/join/WWU4StEm)**

## 一、新增功能与主要改进

### 1. 新增魔改资源管理

工具箱新增 **「魔改」** 功能，可在设备本地导入和管理支持的魔改资源包，替换游戏中的舰娘立绘、语音及相应的坐标配置。

- 支持导入 ZIP 格式魔改包，也可指定本地资源文件夹，扫描其中的 ZIP 或已解压目录后批量导入。
- 支持分别选择普通立绘、中破立绘、坐标及语音资源，并管理多个包的启用状态与优先级。
- 修改完成后，可通过 **「应用并刷新游戏」** 统一应用；尚未应用的修改支持取消。
- 导入、扫描和应用过程中显示处理进度，方便确认当前状态。
- 支持将已应用的魔改头像同步到编队简报、舰娘详情及持有一览，使游戏画面与软件中的舰娘展示更加统一。
- 可关闭魔改或还原原版资源，并保留原有登录信息、普通游戏缓存、设置和记录。

魔改资源需要符合受支持的格式与路径。不同包之间存在资源覆盖时，将按照设置的优先级处理，具体支持情况与未支持项目会在导入预检中说明。

### 2. 新增舰娘语音字幕

新增 **「舰娘语音字幕」** 功能，可在游戏播放舰娘语音时显示对应台词，方便阅读与理解语音内容。

- 支持 **简体中文、繁体中文、日语、英语和韩语** 五种字幕语言。
- 字幕语言独立于应用界面语言，可根据个人习惯单独选择。
- 提供小、中、大三档字号；解除界面锁定后，可通过拖动手柄调整字幕位置。
- 字幕位置会保存，重新打开功能或调整窗口后仍可继续使用。
- 长台词会根据语音时长分页显示，减少文字超出游戏画面的情况。
- 内置字幕资料，并支持在设置中检查更新；开启字幕后，也会定期检查资料更新。

字幕默认关闭，可在设置中手动开启。字幕资料更新下载的是台词与名称文本，不包含游戏语音文件。

### 3. 界面个性化与手机布局升级

本次增加了更多外观和显示方式选项，让手机、小窗口与大屏设备能够根据使用习惯进行调整。

**新增极简界面与标签式简报：**

- 在原有普通、紧凑档位基础上，新增 **「极简」** 界面档位，减少控件占用，改善较小屏幕上的信息展示。
- 增加更简洁的扁平信息面板样式。
- 普通布局下的简报新增 **「标签式」** 展示，可通过标签切换不同模块，减少上下滚动；也可继续使用原有折叠式展示。

**新增主题与字体自定义：**

- 在原版暗色外观之外，新增 **「海盐青」和「晴空蓝」** 两种浅色主题。
- 支持导入 TTF、OTF 字体，并提供预览、应用及恢复默认字体功能。
- 界面显示密度与文字大小可以分别设置，字号支持跟随系统及小、中、大档位。

**完善屏幕适配：**

- 新增摄像头、刘海及挖孔避让设置，可根据设备情况调整避让距离。
- 改善分屏、矮窗口、窄屏及文字放大后的布局，减少内容裁切、遮挡和操作区域拥挤的问题。

### 4. 新增英语与韩语界面

在原有简体中文、繁体中文和日语基础上，新增 **英语和韩语界面**。

- 补充舰娘、装备、舰种及装备类别等名称的英韩显示。
- 舰队、持有一览、任务、开发、改修、经验计算等页面接入相应名称翻译。
- 相关搜索支持识别已接入的原名与译名，方便不同语言用户查找资料。
- 翻译资料支持更新；尚无对应译名的内容继续显示原名。

名称翻译作用于 Yahagi 的辅助界面，不会改变游戏内数据、资源路径或导出数据的原始内容。

### 5. 任务中心与进度追踪增强

继续完善任务资料查询与本地进度追踪，让查找任务、查看条件及安排前后置关系更加方便。

- 重整搜索与筛选，将关键词、类型、周期和状态等条件集中设置，应用前可预览命中数量。
- 完善任务编号查询，并支持使用显示语言中的舰娘、装备名称搜索相关任务。
- 任务详情按 **条件与进度、奖励、关联任务** 分页展示，补全资源奖励、文字奖励及选择奖励的显示。
- 前置任务支持展开追溯，查看关联任务后可返回原任务，方便整理任务链。
- 内置本地进度规则扩充至 **432 个任务**，并支持在设置中独立检查和更新规则。
- 修正部分舰船、舰种、海域节点及同行舰条件，改善周期重置、进度保存和升级后的规则保留。

本地进度依据应用实际观察到的数据累计，部分任务仍只能提供参考计数；是否完成及能否领取奖励，请以游戏内状态为准。

### 6. 「未卜先知」新增海域小地图

「未卜先知」新增 **海域小地图**，可在出击过程中直接查看当前海域的节点与路线，方便结合战斗信息确认行进情况。

- 根据已捕获的出击数据，显示当前节点及本次出击已经过的路线。
- 小地图与实时战斗信息放在一起，无需切换到工具箱查询页面。
- 支持展开和折叠，并适配不同宽度的信息栏，减少小屏设备上的空间占用。
- 调整节点标签与航线布局，减少文字遮挡和线路误读。

小地图根据已取得的游戏数据与海域资料显示；资料暂不可用或捕获不完整时，显示内容可能不完整，请结合游戏画面确认。

### 7. 大破提醒与战斗信息改进

在原有战斗辅助与大破提醒基础上，进一步完善损管信息、提醒时机和游戏内提示的呈现方式。

- 大破提醒合并列出相关舰娘，并检查普通装备槽和补强增设中的 **剩余应急修理要员、应急修理女神**。
- 对未携带损管、携带剩余损管及状态无法确认的情况进行区分，方便核对。
- 支持分别选择 **结算后提醒、进击后提醒**，也可同时开启。
- 支持「始终确认」与「智能提醒」；智能提醒会结合剩余损管及数据可信度，选择顶部提示或确认弹窗。
- 支持本次出击静音，并在提醒中提供手动刷新游戏与框架刷新的入口。
- 「未卜先知」增加本节点的损管发动标记，方便确认本次战斗中的损管使用情况。
- 新增解谜／削甲相关提示提醒，检测到游戏返回的解谜或削弱信号时，可通过弹窗或顶部提示进行提醒。

同时，改善大破、新舰等提示在 Android 原生游戏画面上的显示，减少提醒被游戏画面遮挡、弹窗后画面冻结等问题。

### 8. 战果统计与记录备份完善

继续改善战果记录、日历和目标计算的准确性，并扩展记录备份的范围。

- 优化经验、EO 和任务奖励的战果记录，修正部分重复入账、延迟更新及月底跨月归属问题。
- 改善任务战果奖励识别，减少选择其他奖励时错误计入战果的情况。
- 修正战果日历、今日剩余目标及每日需求的计算，减少排名刷新或计划调整造成的重复扣减。
- 将基础战果的输入与重设集中到战果信息页，方便查看和调整。
- 记录备份新增 **当前账号的战果档案**，在原有航海日志与编成记录基础上保留更多记录。
- 加强备份合并、保存、恢复及中断后的处理，继续兼容已有备份文件。

## 二、修复与体验优化

- **游戏画面与浏览：** 完善 OOI 游戏入口识别和原生画面适配，改善平板、分屏与矮窗口中的缩放、裁切及恢复问题。
- **弹窗与刷新：** 修复部分弹窗和刷新操作导致游戏画面卡住的问题，改善提示显示期间的游戏画面播放与操作体验。
- **未卜先知：** 改善捕获中断后的状态恢复与未确认状态显示，完善战斗信息的同步与刷新。
- **通知与后台：** 优化后台保持和恢复机制，并在设备重启、应用升级或相关权限变化后恢复有效的定时提醒。
- **航海日志：** 改善远征、建造、开发和除籍记录的筛选与分页，减少旧记录未参与筛选或刷新后浏览位置丢失的问题。
- **工具箱与资料更新：** 完善开发、改修、远征、经验计算等页面的名称显示、筛选控件及窄屏适配，减少部分资料处理造成的界面卡顿。
- **界面与设置：** 更新应用图标与顶部标识，重新整理设置分类，并统一主题、切换按钮及筛选控件的显示样式。
- **其他修复：** 修正部分代理路由、缓存恢复、账号切换及记录保存问题，继续改善整体运行稳定性。

## 三、使用提示

- **覆盖升级时无需卸载旧版。** 如准备换机、卸载应用或清理应用数据，请先导出需要保留的记录，并确认备份文件已保存。
- 魔改功能只支持符合要求的资源包。请先查看导入预检结果，再应用到游戏；原始资源包和字体文件建议自行保留。
- 语音字幕需要游戏产生对应的语音播放事件。完全关闭游戏语音时，可能无法显示字幕；部分较旧的系统 WebView 也可能需要更新。
- 本地任务进度、战果估算、海域小地图和战斗提示均用于辅助查看，最终状态请以游戏内实际显示为准。
- 大破提醒不能拦截已经发送的进击请求，也不会自动撤退；携带损管不代表可以忽略游戏内状态确认。
- 解谜／削甲提醒用于提示游戏返回的相关信号，不提供完整活动机关攻略，也不代表全部削甲条件已经完成。
- 记录备份目前包含航海日志、编成记录及战果档案，仍不属于完整的应用数据与设置迁移。
- 后台提醒仍会受到系统权限、省电策略及设备后台管理方式的影响。
