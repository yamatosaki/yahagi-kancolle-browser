# 改修星期与进化筛选统一设计

## 目标

统一改修规划顶部筛选栏的视觉语言，并增加按当天是否可进化筛选的能力；同时将表头和全部单元格内容统一为左对齐。

## 顶部筛选栏

- 周一至周日放在一个连续的圆角胶囊容器内，不再为七个独立胶囊。
- 胶囊内部使用单一高亮滑块表示当前星期；点击其他星期时，高亮块以短动画滑动到目标位置。
- 星期胶囊后保留圆形收藏星标按钮；关闭显示当天全部项目，开启仅显示已收藏项目。
- 收藏按钮后增加连续三段胶囊：`全部`、`可进化`、`不可进化`，默认选择 `全部`。
- `可进化` 表示当天投影行存在至少一条进化路线；`不可进化` 表示当天投影行没有进化路线。
- 收藏条件与进化条件取交集。例如同时选择收藏和不可进化，只显示当天已收藏且不可进化的装备。
- 顶部所有控件位于同一个横向滚动区；窄屏不压缩文字，也不产生布局溢出。

## 表格对齐

- 九列表头全部左对齐，并使用一致的水平内边距。
- 收藏列的星标、装备名称、基础消耗、阶段消耗、进化消耗、秘书舰、可进化状态和进化装备全部左对齐。
- 现有冻结列、横竖滚动、动态行高、①②路线标识和蓝色数量保持不变。

## 状态与测试

- Controller 增加三态 `ImprovementEvolutionFilter { all, evolvable, notEvolvable }`。
- 星期、收藏和进化筛选均只影响页面投影，不修改资料或收藏持久化格式。
- Widget 测试覆盖连体星期胶囊、滑块选择、三态进化筛选、组合筛选、四种屏幕尺寸和表头/单元格左对齐。
