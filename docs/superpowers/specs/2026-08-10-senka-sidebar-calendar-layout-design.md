# 战果 Demo 左栏与日历布局设计

## 目标

- 横屏四档使用左侧 1×3 信息栏和右侧整列战果日历。
- 平板竖屏继续使用 1×4 纵向布局。
- 五档预设均在一个画面内显示全部核心信息，不产生页面或卡片滚动。
- 删除「月度作战进行中」。
- 将顺位改为单行胶囊「当前顺位：431」。

## 横屏布局

大平板、小平板／折叠屏、手机横屏和紧凑横屏使用以下结构：

```text
┌────────────────┬──────────────────────┐
│ 预计当前战果   │                      │
├────────────────┤                      │
│ 本月目标       │      战果日历        │
├────────────────┤                      │
│ EO 与战果任务  │                      │
└────────────────┴──────────────────────┘
```

- 左栏占可用宽度的 42%，右栏占 58%。
- 左栏从上到下依次为预计当前战果、本月目标、EO 与战果任务。
- 右侧日历跨越全部 3 行，使用完整可用高度。
- 左栏三行按内容分配高度：预计当前战果和 EO 与战果任务获得较多空间，本月目标保持紧凑。
- EO 与任务的 4 个状态格继续使用 2×2。
- 日历保留星期、完整 6 行日期、每日战果和选中日期的一行明细。

## 平板竖屏布局

800×1100 平板竖屏继续使用 1×4：

```text
┌──────────────────────────┐
│ 预计当前战果             │
├──────────────────────────┤
│ 本月目标                 │
├──────────────────────────┤
│ EO 与战果任务            │
├──────────────────────────┤
│ 战果日历                 │
└──────────────────────────┘
```

- 不强制左右分栏，避免日历和信息栏过窄。
- 四张卡在应用高度内一次排完，不使用内容区滚动。

## 标题栏

- 删除绿色状态点和「月度作战进行中」文字及其容器。
- 当前顺位使用胶囊样式，内容固定为单行「当前顺位：431」。
- 初始状态中的顺位数据同步改为 `431`，避免只修改视觉文案。
- 顺位胶囊设置 `white-space: nowrap`，不得在任何尺寸换行。
- 返回按钮、页面标题和手动校准按钮保持现有位置与交互。

## 交互与数据

- 保留手动校准、目标输入、模拟自动同步、跨设备缺口开关、状态选择和日期选择。
- 布局变化不修改战果计算公式及 EO／任务状态归类逻辑。
- 自动同步和手动校准后，顺位胶囊继续由状态中的 `rank` 渲染。

## 验收标准

- 1280×680、1024×600、844×390、740×360 均为左 42%／右 58% 布局。
- 横屏右侧日历跨满 3 行，左侧卡片顺序正确。
- 800×1100 为 1×4 纵向布局。
- 五档预设中四张卡均位于应用边界内，内容区与卡片均无非预期滚动。
- 手机两档完整显示星期、6 行日期和选中日期明细。
- 标题栏不存在「月度作战进行中」，顺位胶囊始终单行显示「当前顺位：431」。
- 状态测试、目标输入、自动同步、状态选择、日期选择和手动校准交互全部通过。
