# 战果 Demo 客户端视觉对齐设计

## 目标

将独立“战果”Demo 从通用数据看板风格改为与现有舰队信息中心一致的客户端设计语言，同时保留已经验证过的战果计算与手动校准交互。

## 范围

- 删除“结算时间线”整个模块及其示例数据。
- 删除页面内所有英文眉题，包括 `OPERATIONS / 2026.08`、`MONTHLY TARGET`、`PLANNING`、`7 DAY TREND` 和 `SETTLEMENT`。
- 顶部设备预览工具栏仍属于 Demo 外壳，可以保留中文名称和尺寸读数。
- 不修改战果状态模型、计算公式和校准结果。

## 视觉语言

以 `ui-demos/fleet-overview-v2` 为直接参照：

- 使用深海军蓝背景、海军蓝面板、低对比细边框和客户端金色主强调色。
- 页面标题“战果”使用与舰队页一致的金色标题风格。
- 面板圆角收敛到约 9–12px，取消当前大面积青绿色渐变、强光晕和悬浮式大圆角卡片。
- 青绿色只用于已结算、校准成功等状态；金色用于目标、计划与当前选中项；蓝色用于未结算数据。
- 字号、间距和信息密度向舰队页靠齐，使用紧凑标题栏、数据格与列表行。

## 页面结构

1. 顶部客户端标题栏：返回、金色“战果”、当前顺位、手动校准按钮。
2. 当前战果主面板：预计当前战果、数据完整性和目标进度；圆环改为横向进度表达。
3. 三项数据格：服务器已结算、本机可确认未结算、已计划战果。
4. 本月目标面板：目标输入、预计最终、距离目标和分段进度条。
5. 可用战果计划：保留 EO 与任务两行选择交互，选中态改为客户端金色描边。
6. 近期战果：删除时间线后扩展为底部通栏，保留七日柱状趋势。

## 响应式规则

- 大、小平板保持左右两栏：当前战果在左，目标与计划在右，趋势通栏置底。
- 竖屏按当前战果、目标、计划、趋势顺序单列滚动。
- 两档手机横屏仅显示当前战果与本月目标，隐藏计划和趋势，保证校准按钮及核心数字可操作。
- 保留五档尺寸切换和舞台缩放能力。

## 交互与状态

- 跨设备缺口开关、目标编辑、计划勾选、手动校准加载态和成功提示保持不变。
- 目标输入实时更新预计最终与距离目标。
- 校准成功后更新服务器锚点、清除缺口提示；重复校准不得重复累加。
- 删除时间线后不再展示结算倒计时或月末节点。

## 验收

- 页面内不存在上述英文眉题及结算时间线文案。
- 五档尺寸均无页面级横向溢出。
- 原有六项状态模型测试继续通过。
- 目标编辑、方案选择、缺口提示和手动校准在浏览器中可用。
- 浏览器控制台无错误或警告。
