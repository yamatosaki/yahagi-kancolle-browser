# 顶部战果胶囊导航设计

## 目标

用户在首页普通状态下点击顶部战果胶囊时，切换到客户端现有的战果详情工作区，效果与点击侧栏“战果”按钮一致。

## 交互

- 普通状态：单击战果胶囊，切换到工作区索引 9。
- 普通资源胶囊：维持现有行为，不增加页面跳转。
- 编辑状态：战果胶囊不触发导航，继续用于拖动排序。
- 长按战果胶囊：继续进入顶部项目编辑模式，不影响单击导航。
- 战果功能不可用时：外层不传导航回调，点击不执行跳转。

## 架构

- `CompactResourceBar` 新增可选的战果点击回调，只在普通状态下绑定到战果项目。
- `WorkspaceContextHeader` 接收并向资源栏转发回调，不直接修改工作区状态。
- 主工作区页面传入回调，通过现有 `_workspaceIndex` 状态切换到索引 9。
- 不使用新的路由栈，也不模拟侧栏按钮点击，保证侧栏选中状态、标题与内容区域同步。

## 验证

- 组件测试验证：点击战果触发一次回调，点击普通资源不触发，长按仍进入编辑。
- 首页集成测试验证：点击顶部战果后显示战果页，并使侧栏战果项处于选中状态。
- 相关静态分析与差异格式检查通过。
