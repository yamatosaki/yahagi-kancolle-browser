# 受损呼吸提示双模式设计

## 目标

在不删除现有受损呼吸灯的前提下，新增更醒目的“加强”模式。玩家可在“设置 → 画面 → 界面与布局”中切换；新安装以及从未保存过此设置的用户默认使用加强模式。设置即时生效并持久化，不要求重新加载游戏网页或重启应用。

## 已确认的交互

- 设置项名称：`加强受损呼吸提示`。
- 使用一个开关，而不是下拉框或分段按钮：开启为“加强”，关闭为“普通”。两种状态只有一个二元选择，开关最紧凑，也与同页设置风格一致。
- 设置项位于“界面与布局”卡片内，紧跟“显示模式”之后。
- 默认值为开启。已有用户若本地没有该设置键，也会首次使用加强模式。
- 切换后首页舰队简报和舰队详情中的舰娘受损提示同时更新。

## 两种模式

### 普通

普通模式完整保留当前表现：

- 小破、中破、大破分别沿用现有黄 `#FFC940`、橙 `#F57C00`、红 `#D33D17`。
- 三档统一使用 2400ms 呼吸周期。
- 外框透明度保持 `0.35–1.0`，光晕半径保持 `0.5–11.0`。
- 不向头像内部铺色。

### 加强

加强模式同时使用颜色、速度、光晕和头像内部染色区分受损等级：

| 状态 | HP 范围 | 提示色 | 周期 | 外框 | 头像内部染色 |
| --- | --- | --- | --- | --- | --- |
| 小破 | 50% < HP ≤ 75% | `#FFD34F` | 2200ms | 较弱光晕 | 低透明度淡黄 |
| 中破 | 25% < HP ≤ 50% | `#FF8418` | 1450ms | 中等光晕 | 中等透明度橙色 |
| 大破 | 0 < HP ≤ 25% | `#FF2933` | 760ms | 4px 鲜红边框及强光晕 | 最明显的半透明红色 |

内部染色与外框共用同一呼吸相位，但透明度显著低于外框。染色范围限制在 `ShipHpFrame` 所覆盖的头像区域；舰名、等级、速度、疲劳和机制胶囊不染色。HP 为 0 或健康状态不播放呼吸动画。

## 实现结构

### 设置状态与持久化

将 `enhancedDamagePulse` 布尔值加入现有 `LayoutSettingsStore` 和 `LayoutSettingsController`：

- SharedPreferences 键使用 `layout_enhanced_damage_pulse`。
- `loadEnhancedDamagePulse()` 在键缺失时返回 `true`。
- `setEnhancedDamagePulse()` 先更新内存并通知监听者，再保存到 SharedPreferences，沿用布局设置现有行为。

选择复用布局设置控制器，是因为该控制器已经贯穿应用外壳、画面设置页和首页信息面板，能以最少的新生命周期对象完成即时更新。另行创建专用控制器会增加 main、shell、settings 与测试构造器的传递成本；使用全局静态变量则难以测试和持久化，均不采用。

### UI 与数据流

`ScreenSettingsPage` 监听 `LayoutSettingsController`，显示开关并调用 `setEnhancedDamagePulse`。应用外壳把当前模式传给：

1. `FleetSummaryCard` → `FleetShipStatusCapsule` → `ShipHpFrame`；
2. `FleetInformationCenter` → 舰队列表卡 → `ShipHpFrame`。

设置控制器变化会触发已有 `AnimatedBuilder` 或对应 widget 重建，因此切换立即可见。

### 动画组件

把受损动画周期的职责收拢到 `ShipHpFrame`：它根据模式和 HP 比例选择纯数据规格（颜色、周期、最低透明度、最大光晕、内部染色强度）。这样每艘舰可以拥有与受损等级匹配的周期，并在 HP 跨越阈值或设置模式变化时更新动画周期。

普通模式继续走原参数，保证视觉回退完全一致；加强模式才绘制内部染色层。受损等级到视觉规格的映射保持为可独立测试的纯函数。

## 边界与失败处理

- 当前 HP ≤ 0：使用既有零 HP 灰色，不呼吸、不染色。
- 最大 HP ≤ 0：比例按 0 处理，不启动动画。
- HP 状态跨越小破、中破、大破边界：同一个 widget 更新周期和视觉规格，不残留上一档颜色。
- SharedPreferences 保存失败：界面仍保持本次内存选择，行为与现有布局设置一致；下次启动可能恢复上一次成功保存值。
- 测试或独立使用舰队 widget 时未显式传入模式：默认加强，以匹配产品默认值。

## 测试策略

- Store 测试：缺失键默认 `true`，保存/读取 `false` 和 `true` 正确。
- Controller 测试：默认值加载、切换通知、持久化调用正确。
- 设置页 widget 测试：开关位于画面页，默认开启，点击后更新控制器。
- 纯规格测试：三个 HP 边界映射到正确颜色、周期和强度；普通模式参数与原实现一致。
- 舰队 widget 测试：普通模式三档仍同周期且无内部染色；加强模式三档周期不同，并存在对应内部染色层。
- 回归测试：首页舰队简报与舰队详情都响应同一设置；健康和零 HP 舰不出现受损呼吸层。

## 热重载说明

实现将涉及设置存储接口、控制器构造参数和 widget 构造参数。代码完成后，首次验证应使用绿色“重新运行”以重新初始化持久化控制器；后续只调颜色、透明度或周期时可使用黄色“热重载”。
