# 战果 Demo 状态胶囊与任务跳转设计

## 目标

- 压缩“预计当前战果”卡片，消除无效空白，并把顺位信息移到预计战果数值左侧。
- 将 EO 与战果任务改为四行状态清单，直接展示对应 EO 海域与任务简称。
- 状态颜色只表达完成情况：完成为绿色，未完成或未确认为黄色。
- 任务胶囊可按任务 ID 跳转到“全任务”中的对应任务详情。
- 增大日历文字，同时维持所有预设尺寸单屏完整展示、无滚动、无遮挡。

## 预计当前战果

- 标题栏只保留“预计当前战果”，不再显示顺位胶囊。
- 主数值行从左到右为“当前顺位：431”胶囊和预计战果主数值，两者保持同一行且不换行。
- “服务器已结算”“本机可确认未结算”“已计划战果”三项改为矮胶囊，删除解释性辅助文字，只保留名称与数值。
- 计算公式和现有演示数据不变；排版示例中的数字不作为固定新数据。

## EO 与战果任务

- 状态区采用纵向 1×4：已完成 EO、未完成 EO、已完成任务、未确认任务。
- 每行由状态标题、该组战果合计和可换行的胶囊列表组成。
- 删除组内完成数量，例如不再显示 `3/5/1/6`；保留该组战果合计，例如 `+375`。
- EO 胶囊只显示海域编号，例如 `1-5`。
- 任务胶囊使用“任务代码 + 一个半角空格 + 简称”，例如 `Bq2 Z作战前`；不使用中点或连字符。
- 任务简称映射：
  - `Bq2 Z作战前`
  - `Bq7 三川舰队`
  - `Bq8 泊地周边`
  - `Bq10 Z作战后`
  - `Bq11 海上警备`
  - `Bq12 西方海域`
  - `Bq13 六水战`

## 颜色语义

- 已完成 EO 与已完成任务：绿色背景、绿色边框和浅绿色文字。
- 未完成 EO 与未确认任务：黄色背景、黄色边框和浅黄色文字。
- 颜色不再区分 EO 与任务类型，只区分完成状态。
- 胶囊除颜色外保留明确的分组标题，避免只依赖颜色传递状态。

## 任务详情跳转

- EO 胶囊只用于展示，不跳转。
- 任务胶囊是按钮，保存对应任务的数值 ID。
- HTML Demo 点击任务胶囊后切换到模拟的“全任务”详情画面，自动选中对应任务，并提供返回战果页按钮。
- Demo 详情画面展示任务代码、完整名称、状态和战果值，用于验证映射是否正确。
- 正式客户端落地时复用现有 `onOpenQuest(questId)` 通道，但跳转前必须把 `_questCenterMode` 设为 `QuestCenterMode.all`，再把 `_questCenterInitialQuestId` 设为目标 ID并切换到任务中心。这样未确认任务也能在全任务目录中被选中。

## 响应式布局

- 横屏四档保持左侧 1×3、右侧整列日历，不增加滚动。
- 平板竖屏保持 1×4。
- 左侧重新分配行高：压缩预计战果卡片，把空间让给四行 EO／任务胶囊。
- 紧凑横屏中的任务胶囊允许自然换行，但状态卡自身不得滚动或裁切。
- 日历日期、星期和每日战果字号均提高；紧凑尺寸优先减少卡片内边距与间距，不把文字压回不可读尺寸。

## 验收标准

- 五档预设中所有四张卡片均位于应用边界内，没有页面或卡片滚动。
- 横屏四档完整显示日历星期、六行日期、每日战果和选中日明细。
- 顺位胶囊和预计战果数值在所有尺寸中保持同一行。
- 三个战果分项胶囊明显比当前版本更矮，无解释性辅助文字。
- 四个状态组均显示正确胶囊；完成项为绿色，未完成／未确认项为黄色。
- 状态组不显示完成数量，仍显示各组战果合计。
- 所有任务胶囊文字符合简称和单空格规则。
- 点击任一任务胶囊会进入模拟“全任务”详情并选中正确任务；返回按钮恢复战果页与此前状态。
- 原有手动校准、自动同步、目标输入、日期选择和状态数据更新交互继续工作。
