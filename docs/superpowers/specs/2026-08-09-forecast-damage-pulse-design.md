# 未卜先知受损呼吸提示设计

## 目标

让未卜先知面板中的我方受损舰娘复用首页舰队现有的“普通/加强”受损呼吸规则，使受损状态更容易被识别，同时不干扰敌方信息和非 HP 信息。

## 生效范围

- 仅我方舰队生效，敌方舰队始终保持静态。
- HP 比例大于 0 且不高于 75% 时启用呼吸提示。
- 满血、0 HP、最大 HP 为 0 的 `0/0` 条目不启用呼吸提示。
- 完整模式：舰娘所在行的背景、HP 数字和血条同步呼吸；舰名和 MVP 奖杯保持静态。
- 简洁模式：仅 HP 数字和血条同步呼吸，行背景保持静态。

## 模式与视觉规则

未卜先知跟随画面设置中的“加强受损呼吸提示”开关，并复用现有 `DamagePulseMode` 与 `damagePulseVisualSpec`：

- 普通模式：沿用原有统一颜色与 2400ms 周期。
- 加强模式：按现有阈值区分小破、中破、大破的颜色和周期；小破黄色慢闪，中破橙色较快，大破鲜红色快速闪。
- 设置切换后，当前未卜先知面板立即采用新模式。

## 实现方案

抽取一个可复用的受损呼吸动画组件。组件使用现有视觉规格计算颜色、周期和呼吸相位，并允许调用方分别传入静态内容与需要闪烁的内容。

- HP 数字与血条共享同一动画相位，避免各自闪烁不同步。
- 完整模式把同一相位同时用于行背景色层；舰名和奖杯放在动画透明度之外。
- 简洁模式不创建行背景色层，只包装 HP 数字与血条。
- `LiveBattleCard` 接收当前 `DamagePulseMode`，并向完整、简洁两种子面板传递。

## 测试与验收

- 单元/组件测试覆盖普通与加强模式的规格复用。
- 完整模式验证：我方受损行存在背景、数字和血条呼吸层；舰名与奖杯不在呼吸层中。
- 简洁模式验证：我方受损数字和血条存在呼吸层，但没有行背景呼吸层。
- 两种模式均验证：敌方、满血、0 HP 和 `0/0` 不产生呼吸层。
- 运行相关 Flutter 测试与静态分析。
- 本次仅涉及 Dart UI 与参数传递，常驻 Debug 下使用黄色闪电热重载即可验证。
