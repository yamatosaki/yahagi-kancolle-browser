# 战果当前行与底栏对齐设计

## 目标

- “当前”作为独立的小标题栏，不包含在黄色胶囊内。
- 黄色胶囊只包裹玩家数据行：顺位、顺位变化、战果、战果变化。
- `↓42`、`↑78.8` 与相邻主数字使用相同字号。
- “本月已获得战果 +725”去掉深色底色。
- 左侧月度汇总和右侧日期明细使用同一底栏高度并垂直居中。

## 方案

保留现有 DOM 与三列排名网格。将 `.ranking-current-group` 改为透明、无边框容器；`.ranking-current-label` 采用主表标题栏的颜色与字号；仅 `.ranking-row.player` 保留黄色边框、圆角和底色。排行变化字号继承对应主数字的响应式字号。

底栏使用共享的 `--senka-footer-height`：常规尺寸为 30px，手机横屏与紧凑横屏为 24px。`.matrix-summary` 背景改为透明，左右底栏均使用共享高度、相同的 `align-items: center`，保留顶部分隔线。

## 验收

- 五档尺寸下当前标题不在黄色胶囊中，玩家数据行仍完整可见。
- 四个玩家数字/变化值在各自尺寸下字号一致。
- 左右底栏中心点纵坐标一致，页面无水平或垂直溢出。
- 月度汇总无独立深色背景，交互和已有 4×4 矩阵不受影响。
