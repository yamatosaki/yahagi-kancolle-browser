# 远征详情顶部自适应与任务简报计数移除设计

## 目标

- 远征详情页选择“大成功”后，百分比和检查结果无需横向滑动即可操作和阅读。
- 远征名称始终完整显示，不使用省略号截断。
- 移除任务简报标题旁的 `当前数/上限` 胶囊，不影响任务详情中的具体目标进度。

## 远征详情顶部布局

顶部工具区改为由可用宽度驱动的响应式布局，不再使用横向滚动作为正常交互方式。

在宽度足够时，以下控件保持同一行：

1. 远征选择器；
2. “成功 / 大成功”切换；
3. 大成功概率选择器；
4. 常规检查结果；
5. 大成功检查结果。

概率选择器使用与 `80%` 至 `100%` 内容匹配的紧凑宽度，不再复用宽度为 260 的分段按钮容器。“成功 / 大成功”切换也使用更紧凑的固定最小宽度。远征选择器获得其余空间，但其中的远征名称必须完整显示。

当可用宽度不足以容纳全部控件时，只将两个检查结果整体移到第二行；远征选择器、成功模式和概率选择器仍位于第一行。第二行保持左对齐并允许两个结果按实际文字宽度排列。布局不提供横向滚动。

## 文本与国际化

- 远征名称不设置 `TextOverflow.ellipsis`。
- 控件宽度按当前本地化文字测量或保守最小宽度分配，避免中文、繁体中文和日文切换后重新溢出。
- 检查结果保持单个胶囊内部单行；窄屏通过整组换行解决，不截断结果文字。

## 任务简报

从 `PinnedQuestsSummary` 的 `DashboardCard.titleBadge` 移除任务容量胶囊，并删除仅为该胶囊计算的显示数量及私有组件。

继续保留：

- “需进入任务界面同步信息”与“当前无进行中任务”的状态区分；
- 首页每条任务已有的完成状态；
- 任务详情页中的 `次数/目标次数` 精确进度。
