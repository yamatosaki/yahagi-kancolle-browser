# 客户端完整 UI 本地化设计

## 背景与根因

客户端已经通过 Flutter `gen-l10n` 提供简体中文、繁体中文和日文，但覆盖不完整。三份 ARB 当前均有 374 个业务键和 24 个参数元数据，键集合一致；实际混用语言的根因是部分新页面、控制器错误信息和手工语言分支绕过了 `AppLocalizations`，直接返回或展示中文。

本次修复不改变布局、交互、业务数据和游戏捕获逻辑，只统一用户可见的应用文案来源。

## 目标

- 简中、繁中、日文切换后，应用自身的标题、按钮、筛选项、提示、状态和错误信息全部随语言切换。
- 三份 ARB 的业务键、元数据键和占位符保持一致。
- 新代码不能再次向用户可见 Widget 引入写死的中文。
- 游戏提供的原始内容保持原文，不擅自翻译舰名、装备名、任务正文、海域名或接口返回内容。

## 范围

### 纳入迁移

1. 主导航、工作区标题、设置分页和工具提示。
2. 设置页面：显示、声音、战斗、网络、关于、渲染模式、资料更新及所有校验/错误提示。
3. 舰娘与装备持有列表的应用表头、筛选器、空状态和统计标签。
4. 任务中心的模式、搜索、筛选、详情字段和状态标签。
5. 航海日志的分类、表头、筛选、分页、空状态和操作提示。
6. 战果页面及应用内战果任务/日历标签。
7. 改修规划界面和资料更新提示。
8. 舰队、远征、入渠、建造、战斗面板中由应用生成的通用状态和操作标签。
9. 用户可见的控制器错误、校验结果和 SnackBar 文案。

### 明确排除

- 游戏接口或本地资料库提供的舰名、装备名、任务名/正文、海域名和敌舰名。
- 调试日志、异常内部描述、代码注释、测试夹具与 HTML 测试页，除非其内容会展示给普通玩家。
- 固有品牌名、协议名和技术名，如 DMM、WebView、WebGL、Canvas、Hybrid Composition、HTTP、SOCKS5。

## 架构

### 单一文案源

所有应用 UI 文案进入：

- `lib/l10n/app_zh.arb`
- `lib/l10n/app_zh_Hant.arb`
- `lib/l10n/app_ja.arb`

Widget 通过 `AppLocalizations.of(context)` 读取。需要参数的句子使用 ARB 占位符，不在 Widget 中拼接语言相关句法。枚举不再持有面向用户的 `label` 字符串，由靠近展示层的本地化映射函数转换。

控制器继续返回稳定的错误代码或结构化结果；页面根据错误代码选择本地化文案。暂时无法结构化的错误，至少由页面使用本地化前缀包装，避免直接把中文控制器消息作为主要 UI。

### 游戏数据边界

动态游戏数据通过本地化模板嵌入，例如“舰娘 {name}”“任务 {id}”，但 `{name}`、`{id}` 和游戏正文本身不翻译。这样既保持资料准确，也让周围的应用语法随语言变化。

### 手工本地化清理

删除仅判断 `languageCode == 'ja'` 的二分支做法，统一使用 ARB。现有 `ExpeditionStrings` 等手工三语类在迁移完成后仅保留确有领域格式需要的部分，且必须正确区分 `zh`、`zh_Hant`、`ja`；优先迁入 ARB，避免形成第二套文案系统。

## 自动守卫

新增本地化审计测试，包含三层检查：

1. 解析三份 ARB，断言业务键、元数据键和占位符集合完全一致。
2. 对明确的用户界面目录和文件扫描中文字符串字面量；允许列表只接受有原因的游戏原始数据、内部日志或测试内容，并记录文件与模式，禁止宽泛目录豁免。
3. Widget 测试分别以 `zh`、`zh_Hant`、`ja` 渲染关键入口，断言设置分页、主导航和代表页面显示对应语言，且日文页面不出现已知简中文字样。

守卫只检查用户可见源代码边界，不要求日文文本不含汉字，因为日文本身正常使用汉字。

## 分批实施

1. 建立 ARB 一致性和硬编码守卫的红灯测试。
2. 修复主导航与全部设置页面，形成可复用迁移模式。
3. 修复持有列表与任务中心。
4. 修复航海日志、战果与改修规划。
5. 修复其余舰队、远征、建造和战斗通用 UI。
6. 收紧允许列表，运行生成、格式、静态检查、相关测试和 Android 构建。

每批先写或扩展失败测试，看到预期失败后再迁移生产代码，并单独提交，便于定位回归。

## 翻译原则

- 简中沿用当前产品用语。
- 繁中使用正体字并保持现有舰 C 术语习惯，不机械逐字转换。
- 日文优先使用自然的产品 UI 表达和舰 C 常用术语，不保留中文语序。
- 技术开关先保证含义准确；品牌和技术名保留英文。
- 同一概念使用同一 ARB 键，避免同义词在不同页面漂移。

## 验收标准

- 三份 ARB 的全部键、元数据和占位符一致，`flutter gen-l10n` 无错误。
- 关键入口三语言 Widget 测试通过。
- 自动守卫对新增的用户可见中文硬编码会失败，并报告具体文件和行。
- 本次审计确认的设置分页、帧率标题、战斗设置、改修更新、网络校验、战果导航、持有列表、任务中心、航海日志、战果页面和远征简繁问题全部迁移。
- 本次涉及文件通过 `flutter analyze`，本地化相关测试全部通过，debug APK 可构建。
- 不启动应用、不登录账号；真机视觉与术语验收由用户后续完成。
